# 第三批敌人贴图适配（模板包 14）

本批来源为 `island-slicer-web/output` 的 18、19、20、21、24、26，已逐一参考根目录的 `preview_indexed.png`。101 张源 PNG 原样导入，像素未改动。编号有间断，均按实际文件编号匹配；实际使用与弃用编号、完整部件名称、关节连接、动作目标及来源哈希见 `manifest.json`。

| 编号 | 敌人 | 结构与素材取舍 |
| --- | --- | --- |
| 18 | 炉爆甲虫 | 炉膛背甲倾斜覆盖四条分段炉足；双炉门开合，头甲朝前，后腹与烟道分层，巡铃随链摆动。源图已有炉火，不再叠加第二个熔核。 |
| 19 | 棘壳花 | 两段棘茎连接根球和花冠，空口环内放花眼；左右护瓣、分段刺枝、垂叶及行根独立运动，不叠加闭合花芽。 |
| 20 | 水尸蛭群 | 三条尸蛭分别拆成头、下颚、两段腹、尾鳍和背鳍；错开位置和游动相位，调整朝向避免出击时整条纸片侧对镜头。 |
| 21 | 涡眼浮囊 | 涡流囊、分段潮焰骨冠、眼环与涡眼、垂膜、双鳍和三段潮丝触须；眼眶与眼睛紧贴连接。 |
| 24 | 烬咒灯群 | 三盏咒灯分别拼装灯檐、灯芯、活动笼栏、分段咒幡、垂铃和逸焰；调整间距使三枚灯芯均可辨认，弃用整盏成品贴图。 |
| 26 | 溺影猎手 | 胸肋、颈椎、头、活动下颌、骨盆、双侧分段臂腿和足爪；右手持钩镰，披缕分段摆动。颈、膝、踝按真实骨端搭接，弃用带完整脊柱的整件披风。 |

所有部件为零厚度纸片，根朝向仍为 -30°。游戏统一 1.2 倍显示保留；猎手与咒灯仅微调格子内位置，避免挥镰、出击和死亡时裁边。

版本 13 升级到 14 只替换本批六只，其他 27 只（包括已完成的十二只贴图敌人及其手调数据）保持。被替换的手调旧骨架会保留为“旧版备份”，选中角色和敌人关联保持，持久化后再次加载不会重复迁移。

验收资料：

- `review/overview.png`：最终静止拼装合集。
- `review/editor-*.png`：真实 `/animeedit` WebGL 页面，五种动作各五个时间点，共 150 个最终姿态、30 次播放；猎手腿部修正后又单独复查五种动作。
- `review/orbit-*.png` 和 `review/orbit-overview.png`：18 个实际三维编辑器视角。
- `review/size-*.png` 与 bounds JSON：真实游戏渲染器的 150 个姿态，可见像素均在 160px 格子内。
- `reference-*.png` 为原编号参考图，`input-*.png` 为源部件接触图。

动画及迁移检查、修改文件 ESLint、构建通过。全项目 ESLint 的 42 个既有错误仍位于 `island-slicer-web`，本批没有新增错误。
