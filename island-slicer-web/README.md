# Sprite Island Slicer v10

## 新增
- 图片默认自动适应预览容器宽高
- 鼠标滚轮自由缩放
- `− / + / 适应 / 100%` 控制
- 缩放仅影响显示，不改变原图像素、孤岛识别和导出结果
- 放大后预览区可滚动查看

## 启动
```bash
node server.cjs
```

打开：
```text
http://127.0.0.1:4177
```


## v3 布局调整
- 画布工作区始终占满顶部栏以下的剩余高度
- 右侧参数面板与画布区同高
- 参数项纵向间距进一步压缩
- 参数面板内容超出时内部滚动
- 参数面板滚动条隐藏


## v4 画布交互
- 画布区域不再出现水平/垂直滚动条
- 放大后超出容器范围的部分直接裁切
- 鼠标左键按住拖动即可平移图片
- 鼠标滚轮以鼠标所在位置为中心缩放
- “适应”重新居中并完整显示图片
- “100%”切换到原始像素倍率并保持视图中心


## v5 抠图预览状态
- 初始状态只显示原始贴图，不显示抠图高亮、边缘、编号或外接框
- 点击“抠图预览”进入预览状态
- 预览状态默认勾选“显示原贴图”
- 取消“显示原贴图”后，仅显示透明棋盘上的孤岛蓝灰蒙版、边缘和编号
- 预览状态下“抠图预览”按钮变为“更新预览”，修改参数后可重新计算
- “取消预览”恢复初始显示，但保留已经计算的分析结果，方便再次预览或批量导出


## v6 最小面积辅助判断
- “最小面积”标题后实时显示当前已拆出部件中的最小面积
- 同时显示该部件在预览中的编号，例如 `当前最小：#17 · 236 px`
- 每次重新分析/更新预览后自动刷新
- 切换素材时显示该素材最近一次分析结果；尚未分析则显示 `—`


## v7 部件快速浏览
- 右侧增加当前预览的部件列表
- 每项显示部件编号、外接框尺寸、连通域面积
- 点击某项后只高亮该部件，其他孤岛自动压暗
- 当前选中项会自动滚动到列表可见区域
- 在预览状态下可用 ↑ / ↓ 循环切换部件
- 参数滑杆或下拉框获得焦点时，不抢占其方向键
- 列表获得焦点时按 Esc 可取消单部件选择，恢复全部孤岛预览


## v8 左侧「素材 / 部件」双导航
- 左侧改为 `素材 / 部件` 两个 Tab
- 素材 Tab 显示全部导入图片
- 部件 Tab 显示当前图片已经识别出的部件列表
- 进入“抠图预览”时自动切换到部件 Tab
- 点击“取消预览”时自动切回素材 Tab
- 右侧参数面板只保留抠图参数、预览开关和统计信息
- 部件 Tab 顶部始终显示当前素材文件名
- 两个 Tab 都显示数量：素材数量 / 当前部件数量
- 只有在部件 Tab 中，↑ / ↓ 才用于快速切换部件


## v9 部件列表高度与滚动条
- 部件列表固定占满左侧栏剩余高度，一直到页面底部
- 超出的部件只在列表内部滚动
- 部件列表使用 6px 窄滚动条
- 滚动条采用深灰轨道和稍亮滑块，与整体暗色界面统一

## v10 手动合并部件
- 部件列表每行右侧增加合并图标，点击后选择要合并到的目标部件
- 目标列表支持按编号搜索，并显示独立部件缩略图和尺寸
- 悬停或通过方向键选择目标时，画布同时突出显示源部件（橙色）与目标部件（蓝色）
- 合并保留目标编号，更新部件数量、面积、外接框和导出结果；分离区域之间保持透明
- “撤销合并”按操作顺序逐次恢复，切换素材或取消预览会保留各素材的合并记录
- 重新分析成功后重置手动合并；存在合并记录时，分析按钮旁显示提示
- Esc、关闭按钮或点击弹窗外部可取消目标选择
