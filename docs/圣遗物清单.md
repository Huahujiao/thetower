# 圣遗物清单

当前运行时代码包含 35 件圣遗物。收藏数量不设上限，同时最多激活 5 件；未列出的旧版圣遗物不再进入奖励池、商店或图鉴。

| ID | 圣遗物 | 当前效果 |
| --- | --- | --- |
| r-packed-core | 满载核心 | 背包占满时，攻击伤害 ×1.5。 |
| r-empty-core | 空囊狂想 | 背包为空时，攻击伤害 ×3。 |
| r-backline-ricochet | 弹道折射 | 主攻击后，对目标身后第一格造成同等伤害，必要时翻开该牌。 |
| r-long-flip | 远见指环 | 翻牌时可走到距离目标不超过 2 格的最近可通行位置再翻牌。 |
| r-unseen-force | 未见之力 | 每有 1 张当前可翻开的牌，攻击 +1。 |
| r-side-glance | 侧目微光 | 翻牌时随机窥视八邻域内 1 张未翻牌。 |
| r-delay-spark | 迟滞火种 | 翻开敌人牌时，其行动延迟 +1。 |
| r-double-edged-fate | 双刃命运 | 造成和受到的伤害都 ×2。 |
| r-blood-prism | 饮血棱镜 | 武器因最后一击损毁后，恢复该次主攻击对主目标直接造成生命伤害的 30%，向下取整且至少 1。 |
| r-tide-heart | 潮汐心脏 | 连续主攻击交替使用左右手时，第二次结算后恢复 2 生命。 |
| r-bounty-tax | 猎金税 | 每击败 1 名敌人获得 1 金币。 |
| r-healer-forge | 疗愈炼成 | 每次实际恢复生命时，随机一把已装备武器攻击 +1。 |
| r-armor-echo | 甲胄回响 | 武器因最后一击损毁时护甲 +5；若同时直接击杀主目标，再 +3。 |
| r-coinweight | 钱币压舱 | 每持有 10 金币，攻击 +1。 |
| r-arsenal-gallery | 军械陈列 | 背包中有至少 7 把武器时，伤害 ×1.7。 |
| r-clearing-protocol | 清道协议 | 击败敌人时，若没有其他已翻开敌人，随机翻开 1 张未翻牌。 |
| r-vanguard-strike | 先锋一击 | 每房间第一次攻击不消耗耐久；对尚未行动的敌人伤害 +2。 |
| r-vanguard-bounty | 先锋赏金 | 每房间首杀获得 2 金币并修复当前武器 1 耐久（最后一击不修复）。 |
| r-war-spirit | 连击战意 | 每房间击败敌人获得战意层数，最多 3 层，每层攻击 +2；拾取资源失去 1 层，离房清空。 |
| r-residual-lens | 残局透镜 | 房间仅剩 1 名敌人时，翻开并标记它。 |
| r-final-duel | 末战誓约 | 房间最后 1 名敌人受到的伤害和造成的伤害都 +30%。 |
| r-requiem-anvil | 安魂铁砧 | 清场时修复已装备武器中耐久最低者 2 点。 |
| r-retaliatory-salve | 回响软膏 | 每回合受到伤害后，在回合结束前按受击次数恢复生命。 |
| r-floor-roar | 层境怒吼 | 跨层累计每击败 10 名敌人，翻开当前楼层所有敌人。 |
| r-inheritance-edge | 断刃继承 | 每损毁 1 把武器，使另一把已装备武器攻击 +2。 |
| r-tenth-alchemy | 炼金脉搏 | 跨层每第 10 次发起攻击，将目标变为其当前生命等额金币。 |
| r-victory-near | 胜利在望 | 已发现出口时，敌人距离出口 1–5 格分别受到 +5 至 +1 伤害。 |
| r-breaker-spark | 破碎火花 | 武器损毁时优先对主目标，否则对随机敌人造成 3 伤害。 |
| r-bomb-expert | 拆弹专家 | 翻开陷阱时无视其效果，并恢复 5 护甲和 5 生命。 |
| r-weapon-foundry | 流动兵库 | 每发起 3 次攻击，随机武器进入背包；无空位时跳过。 |
| r-whetstone-echo | 磨石回声 | 用磨刀石修复一把手中武器时，另一只手武器也增加 1 耐久。 |
| r-gray-divination | 灰签卜筮 | 玩家主动翻开 4 张灰白中性卡背后，随机窥视一张仍未翻开的属性卡背；计数跨房间保留。 |
| r-scrap-charm | 废铁护符 | 每房间最多 1 次，主动丢弃背包武器时获得 5 护甲；装备武器和自然损毁不触发。 |
| r-death-burst | 死亡爆裂 | 敌人死亡时对八邻域敌人造成 2 伤害并翻开其中未翻牌。 |
| r-key-echo | 钥匙回响 | 拾取钥匙时，翻开对应门 arrival tile 周围八邻域牌。 |
