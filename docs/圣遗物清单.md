# 圣遗物清单

当前运行时代码包含 30 件圣遗物。圣遗物作为背包中的 1×1 普通物品，持有时通常立即生效；超过 5 件后所有圣遗物暂时失效，减少到 5 件或以下后恢复生效。丢弃或出售后会重新进入随机候选池；未列出的旧版圣遗物不进入奖励池、商店或 `/wiki` 运行时页面。

| ID | 圣遗物 | 当前效果 |
| --- | --- | --- |
| r-packed-core | 满载核心 | 背包占满时，攻击伤害 ×1.5。 |
| r-empty-core | 空囊狂想 | 背包为空时，攻击伤害 ×3。 |
| r-backline-ricochet | 弹道折射 | 每次攻击后，对目标身后第一格造成同等伤害，若该格未翻开则同时翻开。 |
| r-long-flip | 远见指环 | 翻牌时可走到距目标不超过 2 格的最近可通行位置再翻牌。 |
| r-unseen-force | 未见之力 | 每有 1 张当前可翻开的卡牌，攻击 +1。 |
| r-side-glance | 侧目微光 | 每次翻开卡牌时，随机窥视其 8 邻域中 1 张未翻牌（半透明显示）。 |
| r-delay-spark | 迟滞火种 | 翻开敌人牌时，其行动延迟 +1。 |
| r-double-edged-fate | 双刃命运 | 造成的伤害与受到的伤害都 ×2。 |
| r-tide-heart | 潮汐心脏 | 连续两次主攻击分别使用不同武器时，第二次攻击后回复 2 点生命。 |
| r-bounty-tax | 猎金税 | 每击败 1 名敌人，获得 1 金币。 |
| r-healer-forge | 疗愈炼成 | 每次回复生命时，随机使 1 把背包武器攻击 +1。 |
| r-coinweight | 钱币压舱 | 每持有 10 金币，攻击 +1。 |
| r-arsenal-gallery | 军械陈列 | 背包中有 7 把及以上武器时，伤害 ×1.7。 |
| r-clearing-protocol | 清道协议 | 击败敌人时，若房间没有其他已翻开的敌人，随机翻开 1 张未翻牌。 |
| r-vanguard-strike | 先锋一击 | 每个房间的第一次攻击，对尚未行动过的敌人伤害 +2。 |
| r-vanguard-bounty | 先锋赏金 | 每个房间首杀时，获得 2 金币。 |
| r-war-spirit | 连击战意 | 本房间每击败 1 名敌人获得 1 层战意（最多 3 层）；每层攻击 +2。拾取物品、金币或钥匙时失去 1 层；离开房间清空。 |
| r-residual-lens | 残局透镜 | 房间仅剩最后 1 名敌人时，翻开并标记它。 |
| r-final-duel | 末战誓约 | 房间最后 1 名敌人受到的伤害 +30%，但其对玩家造成的伤害也 +30%。 |
| r-requiem-anvil | 安魂铁砧 | 房间清场时，恢复 2 点体力。 |
| r-retaliatory-salve | 回响软膏 | 每回合内，每受到 1 次伤害，回合结束前回复 1 点生命。 |
| r-floor-roar | 层境怒吼 | 跨层累计每击败 10 名敌人，翻开当前楼层的所有敌人。 |
| r-tenth-alchemy | 炼金脉搏 | 跨层计数，每第 10 次攻击直接将目标变为其当前生命等额的金币。 |
| r-victory-near | 胜利在望 | 已发现出口时，敌人距出口 1/2/3/4/5 格分别受到 +5/+4/+3/+2/+1 伤害。 |
| r-bomb-expert | 拆弹专家 | 翻开陷阱牌时，无视其效果，并回复 5 点护甲与 5 点生命。 |
| r-weapon-foundry | 流动兵库 | 每发起 3 次攻击，将 1 把随机武器放入背包（无空位时跳过）。 |
| r-gray-divination | 灰签卜筮 | 每当玩家主动翻开 4 张显示为中性灰白卡背的卡牌后，随机窥视当前房间 1 张属性卡牌。计数跨房间保留，自动翻开、圣遗物翻开和窥视不计数。 |
| r-scrap-charm | 废铁护符 | 每个房间最多 1 次：主动丢弃一把位于背包中的武器时获得 5 点护甲。 |
| r-death-burst | 死亡爆裂 | 敌人死亡时，对其 8 邻域敌人造成 2 点伤害，并翻开其中的未翻牌。 |
| r-key-echo | 钥匙回响 | 拾取钥匙时，揭示对应门周围的 8 邻域卡牌。 |

圣遗物的精确事件实现位于 `src/game/data/relics.js`；游戏内 `/wiki` 直接读取同一份定义。旧版设计记录见 [旧版圣遗物.md](./旧版圣遗物.md)。
