# 当前圣遗物清单

共6件，全部占1格且不可旋转。持有时生效，同名唯一；没有超载数量限制。敌人不再掉落圣遗物。

| 名称 | 属性 | 效果 |
| --- | --- | --- |
| 三相轮 | 中性 | 背包同时持有三种属性武器时，克制倍率变为2.2，被克制倍率变为0.5。 |
| 空匣印 | 中性 | 背包空格≥8时，所有武器体力消耗-1。 |
| 逆克石 | 中性 | 所有武器的属性克制关系反转：原本克制变为被克制，原本被克制变为克制。 |
| 旅者骨牌 | 中性 | 移动后立即进行的武器攻击体力消耗-2；连续攻击时体力消耗+1。 |
| 血契铜镜 | 枯萎 | 所有治疗量减半并向下取整；生命≤50%时，武器攻击+3。 |
| 断刃秤 | 中性 | 背包恰好只有一把武器时，该武器攻击+4、射程+1。 |

圣遗物用于改变资源、属性或背包构筑规则；具体结算顺序见[新版设计](./thetower_全新物品系统设计.md)。
