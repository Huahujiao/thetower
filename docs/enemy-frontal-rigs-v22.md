# 正向骨架与腐根芽重规划（V22）

2026-10-09。对应猩鬼 `gnawer`、腐根芽 `rootrot-bud` 和 `/animeedit` 角色选择器。

## 正向骨架

静止姿态中，所有成对关节的 X 互为相反数，Y、Z 一致，父子结构和旋转互为镜像。检查包含手腕、膝、跗节、踝、叶端和着地点，并分别验证原始骨架与接地后的实际显示骨架。

左右原图的少量尺寸差异使用相同的骨架坐标标尺。猩鬼保留已抬高的上身和髋部；腿部各节使用一致的小幅深度递进，左右对应节点保持同深度。脚底贴图的细微高度差在部件位置上补偿，避免接地约束单独掰弯一条腿。着地点不再随任意轮廓顶点的排列偏向一侧。

## 腐根芽

依据 [原始部件图](../art/enemies/03腐根芽.png)，采用“眼芽—主茎—根球—两侧行根”的中心结构，两张大叶从主茎向外展开。共使用 7 张源图、11 个可动部件。

| 部位 | 源图编号 | 连接方式 |
| --- | --- | --- |
| 眼芽 | 006 | 单独的完整头部，根须搭接主茎顶端 |
| 主茎 | 008 | 保留上部 68%，裁去会遮住根球和行根的下部根须 |
| 根球 | 012 | 身体基座，连接主茎与两侧行根 |
| 大叶 | 002、003 | 沿叶柄与中脉拆为两段，保留实际叶端节点 |
| 行根 | 014、013 | 014 在负 X 侧、013 在正 X 侧，按真实根口和爪部节点向外展开 |

开放花冠 001、第二张茎 011、小叶 009/010、刺枝 004/005、独立眼 007 和附加根刺 015/016 本轮不叠加。待机轻微起伏，移动交替抬根，攻击由主茎俯仰与双叶展开驱动，死亡向前伏倒。

V22 为已有猩鬼重新生成接地节点，为腐根芽更换规划后的骨架、部件及动作。编辑过的旧腐根芽保留为旧版备份；角色选择和已有猩鬼动作保持。

## 编辑器与验证

角色选择器仍采用原生 `select`，修正被通用字体规则覆盖的问题，设置为 11px 字号、26px 高度、最大 240px 宽度。

专项动画、接地检查及修改文件的 ESLint 检查通过。实际 Three.js 预览核对两只敌人各 25 个动作姿态，并验证 V21 浏览器缓存更新到 V22 后的角色选择及默认 3D 模式。

历史 `shadow-rig-check.mjs` 仍在巡路犬的旧器官动作用例处失败，用本轮修改前的代码也能复现。该问题已有 [机制冲突记录](mechanic-conflicts.md)，本轮只更新直接受腐根芽精简影响的部件数量断言。
