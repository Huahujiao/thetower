# 回合、移动与战斗

## 回合消耗

| 操作 | 是否消耗回合 |
| --- | --- |
| 移动、翻牌、攻击、拾取、通过门、使用磨刀石 | 是 |
| 更换装备 | 是 |
| 使用生命药水、护甲药剂、增益物品 | 否 |
| 丢弃物品、整理背包、移动背包物品、旋转物品 | 否 |

每次消耗回合时先递增回合数，触发回合开始事件；随后当前房间中已翻开的敌人按翻开顺序结算行动，最后触发回合结束事件。

## 移动与寻路

- 角色移动、近战相邻和翻牌邻域均使用八方向。
- 寻路以加权距离选择最短路线：水平或垂直移动成本为 1，对角移动成本为 √2。
- 当前攻击射程使用曼哈顿距离，不考虑遮挡；
- 角色经过已翻开的敌人攻击范围时，若该敌人的行动延迟已结束、普通攻击不在冷却中，且本次行动并非前往攻击该敌人，则该敌人有 30% 概率拦截，立即造成其一半攻击伤害；被拦截时移动停止。目的地是否仍在攻击范围内不影响判定。
- 点击角色八邻域内的棋盘目标时直接执行。其他目标第一次点击只预览该行动的实际最短路径；再次点击同一目标才执行。点击其他格子会替换预览路径。路径中存在符合拦截条件的步进时以红色虚线提示风险；未知牌与伏击等未公开信息不作额外提示。

## 敌人行动

敌人的攻击、生命、射程、行动延迟、普通攻击冷却、行为、被动特性和死亡规则均由静态定义决定。同一种敌人无论出现在哪一层，属性完全相同；楼层只根据每种敌人定义的首次出现楼层决定它何时进入生成池。

敌人只按普通攻击行动；追猎敌人可以先移动、后攻击。行动延迟约束普通攻击的首次行动；被动特性不受此限制。带有警报特性的敌人在自身被翻出时，会唤醒距离最近的一名未翻开敌人；被警报连带翻出的敌人不会再次触发警报。

冷却数值表示攻击间隔：冷却 1 表示每回合都可以攻击，冷却 2 表示中间等待 1 回合后再次攻击。运行时以“冷却数值减一”作为等待回合数，没有冷却0的情况。

完整行动顺序、冷却和被动规则见 [敌人规则.md](./敌人规则.md)，具体敌人对象见 [敌人.md](./敌人.md)。

## 玩家攻击

攻击前必须先选中左手或右手的一把武器；角色随后走到该武器能命中的最近位置，并且本次攻击只使用这一把武器。武器相关天赋按武器类别或属性生效。未选中有效武器时点击敌人不会行动，也不会徒手攻击。

伤害按以下顺序结算：

1. 武器基础攻击与天赋、一次性增益的固定加成。
2. 耐久为1时，触发该武器类别的最后一击效果；普通攻击消耗1点耐久，满足天赋或圣遗物条件时可保留耐久。
3. 属性克制或受制倍率。
4. 圣遗物与地形修正。

属性克制循环为「灼热 → 枯萎 → 沉溺 → 灼热」。攻击属性克制目标属性时伤害为 ×1.6；攻击属性被目标属性克制时伤害为 ×0.65；同属性或不构成克制时为 ×1。完整的属性、卡背与卡面规则见 [12-attributes.md](./12-attributes.md)。护甲先吸收受到的伤害，剩余部分才扣除生命。战斗日志显示为“减 X 血，减 Y 甲”；伤害全被护甲吸收时只显示“减 X 甲”。武器类别的普通特效与最后一击见 [weapon.md](./weapon.md)；额外命中不会再次触发武器特效。武器耐久降至 0 时立即损毁，并从对应装备栏移除。
