# 回合、移动与战斗

## 回合消耗

| 操作 | 是否消耗回合 |
| --- | --- |
| 移动、翻牌、攻击、拾取、通过门、使用磨刀石、等待 | 是 |
| 更换装备 | 是 |
| 使用生命药水、护甲药剂、增益物品 | 否 |
| 丢弃物品、整理背包、移动背包物品、旋转物品 | 否 |
| 使用圣遗物主动技能 | 由技能效果决定；当前主动技能不额外消耗回合。 |

每次消耗回合的行动结束后，当前房间中已翻开的敌人按翻开顺序结算行动，随后圣遗物的回合事件与冷却一并更新。

## 移动与寻路

- 角色移动、近战相邻和翻牌邻域均使用八方向。
- 寻路以加权距离选择最短路线：水平或垂直移动成本为 1，对角移动成本为 √2。
- 当前攻击射程使用曼哈顿距离，不考虑遮挡；射线与阻挡规则属于后续扩展，见 [10-roadmap.md](./10-roadmap.md)。
- 角色经过已翻开的敌人威胁范围后又离开该范围时，该敌人有 30% 概率拦截，立即造成其一半攻击伤害；被拦截时移动停止。
- 点击角色八邻域内的棋盘目标时直接执行。其他目标第一次点击只预览该行动的实际最短路径；再次点击同一目标才执行。点击其他格子会替换预览路径。路径进入已翻开敌人的攻击范围时以红色虚线提示风险；未知牌与伏击等未公开信息不作额外提示。

## 敌人行动

敌人的攻击、生命、射程、行动间隔、初次行动延迟、行为、特性与死亡规则均由静态定义决定。同一种敌人无论出现在哪一层，属性完全相同；楼层只决定它何时进入生成池。

- **驻守**：不移动，射程内且冷却归零时攻击。
- **追猎**：射程外时沿已翻开的最短路线朝玩家移动一格；进入射程后攻击。
- **巡逻**：沿生成时确定的路线移动；进入射程后攻击。
- **伏击**：玩家进入附近时立即翻开并攻击一次；之后按驻守规则行动。
- **召唤**：不进行普通攻击，每 3 回合召唤一只无战利品仆从。
- **自爆**：玩家累计 3 回合停留在射程内后造成完整自爆伤害；提前击杀只造成小自爆伤害。

翻开敌人时，它从自身的初次行动延迟开始计时。初次行动延迟为 1 的敌人刚翻开后不会在同一回合立即攻击；只有延迟为 0 的敌人才会当场发动行动。敌人攻击后进入自身的行动间隔冷却。

盾兵、重甲、再生、分裂、复活与召唤等特性的完整规则，以及首批敌人的固定数值，见 [敌人.md](./敌人.md)。

## 玩家攻击

攻击目标时，角色先走到任一已装备武器能命中的最近位置，再按装备栏顺序使用所有可命中的武器。对应手的力量会加入该武器的基础攻击；双手武器使用左右手力量之和。每次攻击会进行一次对应手掌控的耐久保留判定，未保留时消耗 1 点耐久。双手武器使用左右手掌控之和，但每次攻击只判定一次。

未装备可用武器时，角色仍可进行射程为 1 的徒手攻击，固定造成 1 点伤害；徒手攻击不受力量、掌控和属性适应影响。

伤害按以下顺序结算：

1. 武器基础攻击、对应手力量与一次性增益的固定加成。
2. 剩余 1 点耐久时，武器本次伤害减半；若本次触发掌控的耐久保留，则不减半。
3. 属性克制或受制倍率；对应手已选择该武器属性适应时使用强化倍率。
4. 圣遗物与地形修正。

属性循环为「灼热 → 黏液 → 结晶 → 湍流 → 灼热」。攻击属性克制目标属性时伤害为 ×1.6；攻击属性被目标属性克制时伤害为 ×0.65；同属性或不构成克制时为 ×1。已适应该武器属性的手会将这两个倍率改为 ×1.8 与 ×0.8。完整的属性、卡背与卡面规则见 [12-attributes.md](./12-attributes.md)。护甲先吸收受到的伤害，剩余部分才扣除生命。武器耐久降至 0 时立即损毁，并从双手装备栏移除。
