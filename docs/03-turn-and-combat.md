# 回合、移动与战斗

## 回合消耗

| 操作 | 是否消耗回合 |
| --- | --- |
| 移动、翻牌、攻击、拾取、通过门、使用磨刀石 | 是 |
| 更换装备 | 是 |
| 使用生命药水、护甲药剂、增益物品 | 否 |
| 丢弃物品、整理背包、移动背包物品、旋转物品 | 否 |
| 使用圣遗物主动技能 | 是；当前主动技能按钮动作会正常推进 1 个回合。 |

每次消耗回合时先递增回合数并递减圣遗物主动技能冷却，触发回合开始事件；随后当前房间中已翻开的敌人按翻开顺序结算行动，最后触发回合结束事件。

## 移动与寻路

- 角色移动、近战相邻和翻牌邻域均使用八方向。
- 寻路以加权距离选择最短路线：水平或垂直移动成本为 1，对角移动成本为 √2。
- 当前攻击射程使用曼哈顿距离，不考虑遮挡；射线与阻挡规则属于后续扩展，见 [10-roadmap.md](./10-roadmap.md)。
- 角色经过已翻开的敌人威胁范围后又离开该范围时，该敌人有 30% 概率拦截，立即造成其一半攻击伤害；被拦截时移动停止。
- 点击角色八邻域内的棋盘目标时直接执行。其他目标第一次点击只预览该行动的实际最短路径；再次点击同一目标才执行。点击其他格子会替换预览路径。路径进入已翻开敌人的攻击范围时以红色虚线提示风险；未知牌与伏击等未公开信息不作额外提示。

## 敌人行动

敌人的攻击、生命、射程、行动延迟、普通攻击冷却、行为、被动特性、死亡规则和主动技能均由静态定义决定。同一种敌人无论出现在哪一层，属性完全相同；楼层只决定它何时进入生成池。

敌人可同时拥有普通攻击和一个主动技能，两者冷却独立；主动技能可用时优先于普通攻击，但同一敌人在一次结算中不会同时发动两者。追猎敌人可以先移动、后攻击。行动延迟共同约束普通攻击和主动技能的首次行动；被动特性不受此限制。带有警报特性的敌人在自身被翻出时，会唤醒距离最近的一名未翻开敌人；被警报连带翻出的敌人不会再次触发警报。第一层起始房间不生成伏击敌人。

冷却数值表示攻击间隔：冷却 1 表示每回合都可以攻击，冷却 2 表示中间等待 1 回合后再次攻击。运行时以“冷却数值减一”作为等待回合数，不使用冷却 0。

完整行动顺序、冷却、自爆、召唤和被动规则见 [敌人规则.md](./敌人规则.md)，具体敌人对象见 [敌人.md](./敌人.md)。

## 玩家攻击

攻击前必须先选中左手或右手的一把武器；角色随后走到该武器能命中的最近位置，并且本次攻击只使用这一把武器。对应手的力量、掌控和属性适应只作用于该手的武器。未选中有效武器时点击敌人不会行动，也不会徒手攻击。

伤害按以下顺序结算：

1. 武器基础攻击、对应手力量与一次性增益的固定加成。
2. 耐久为 1 时不再减半，而是触发该武器类别的最后一击效果；普通攻击消耗 1 点耐久，掌控可使普通攻击保留耐久。
3. 属性克制或受制倍率；对应手已选择该武器属性适应时使用强化倍率。
4. 圣遗物与地形修正。

属性循环为「灼热 → 枯萎 → 沉溺 → 灼热」。攻击属性克制目标属性时伤害为 ×1.6；攻击属性被目标属性克制时伤害为 ×0.65；同属性或不构成克制时为 ×1。已适应该武器属性的手会将这两个倍率改为 ×1.8 与 ×0.8。完整的属性、卡背与卡面规则见 [12-attributes.md](./12-attributes.md)。护甲先吸收受到的伤害，剩余部分才扣除生命。战斗日志显示为“减 X 血，减 Y 甲”；伤害全被护甲吸收时只显示“减 X 甲”。武器类别的普通特效与最后一击见 [weapon.md](./weapon.md)；额外命中不会再次触发武器特效。武器耐久降至 0 时立即损毁，并从对应装备栏移除。
