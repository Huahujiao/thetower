# 回合、移动与战斗

## 回合消耗

| 操作 | 是否消耗回合 |
| --- | --- |
| 移动、翻牌、攻击、拾取、通过门、使用磨刀石、等待 | 是 |
| 更换装备 | 是 |
| 使用生命药水、护甲药剂、增益物品 | 否 |
| 丢弃物品、整理背包、移动背包物品、旋转物品 | 否 |
| 使用圣遗物主动技能 | 由技能效果决定；当前主动技能不额外消耗回合。 |

每次消耗回合的行动结束后，当前房间中已翻开的敌人按翻开顺序结算行动，随后圣遗物的回合事件与冷却一并更新。

## 移动与寻路

- 角色移动、近战相邻和翻牌邻域均使用八方向。
- 寻路以加权距离选择最短路线：水平或垂直移动成本为 1，对角移动成本为 √2。
- 当前攻击射程使用曼哈顿距离，不考虑遮挡；射线与阻挡规则属于后续扩展，见 [10-roadmap.md](./10-roadmap.md)。
- 角色经过已翻开的敌人威胁范围后又离开该范围时，该敌人有 30% 概率拦截，立即造成其一半攻击伤害；被拦截时移动停止。

## 敌人行动

当前敌人的行为为“驻守”：敌人不移动，只在玩家进入自身射程且冷却归零时攻击。

- 每种敌人拥有攻击、射程、行动间隔和初次行动延迟。
- 翻开敌人时，它从自身的初次行动延迟开始计时。
- 大多数敌人的初次行动延迟为 1，因此刚翻开后不会在同一回合立即攻击。
- 仅初次行动延迟为 0 的迅捷敌人会在翻开时当场攻击。
- 敌人攻击后进入其完整行动间隔冷却。

## 玩家攻击

攻击目标时，角色先走到任一已装备武器能命中的最近位置，再按装备栏顺序使用所有可命中的武器。每把武器一次攻击消耗 1 点耐久。

伤害按以下顺序结算：

1. 武器基础攻击与一次性增益的固定加成。
2. 剩余 1 点耐久时，武器本次伤害减半。
3. 伤害类型克制或受制倍率。
4. 圣遗物与地形修正。

伤害类型关系如下：

| 武器类型 | 克制 | 受制 |
| --- | --- | --- |
| 劈砍 | 血肉 | 硬壳 |
| 穿刺 | 硬壳 | 灵体 |
| 钝击 | 灵体 | 血肉 |

克制倍率为 ×1.6，受制倍率为 ×0.65。护甲先吸收受到的伤害，剩余部分才扣除生命。武器耐久降至 0 时立即损毁，并从双手装备栏移除。
