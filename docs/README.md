# 地牢翻牌冒险：设计文档

这是当前游戏规则、内容和界面的文档入口。运行时静态数据位于 `src/game/data/`；规则或数值改变时，应同步更新对应文档，并用项目检查脚本验证。

## 产品概览

玩家在由方形卡牌构成的五层地牢中探索八个房间。翻牌会带来敌人、武器、物品、资源或陷阱；玩家在逐格移动、敌人阶段、体力管理和 5 行 × 9 列背包之间做取舍，最终击败第五层的监视者并逃离地牢。

游戏入口为 `/`，图鉴入口为 `/wiki`。主界面面向竖屏手机，图鉴是独立的可滚动阅读页面。

## 当前版本

当前物品与天赋已重构，优先阅读[全新物品系统设计](./thetower_全新物品系统设计.md)。44种物品、20个天赋；全部防具被动，整理与合成消耗回合。

## 规则与数据的权威来源

游戏运行时以 `src/game` 为准，`src/legacy` 仅保留历史架构，不属于当前入口。图鉴的已实装卡片直接读取静态数据定义。

当前版本以新版设计为准。移动、翻牌、拾取和普通交互恢复1体力；成功整理、合成和使用消耗品推进回合但不自动回体力。圣遗物无数量超载限制。存档版本22，旧局不迁移。
