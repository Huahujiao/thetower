# 地牢翻牌冒险：设计文档

这是游戏规则、内容和界面的唯一文档入口。本文档集只描述当前产品应呈现的样子；规则、数值与交互变更时，应同步更新对应页面。

## 产品概览

玩家在一座由方形卡牌构成、外沿有墙与边界门的地牢中探索五层、十二个房间。翻开未知卡牌会带来敌人、装备、资源与陷阱；玩家需要在路线选择、战斗风险和 4×6 背包空间之间取舍，最终击败第五层的监视者并逃离地牢。

游戏入口为 `/`，图鉴入口为 `/wiki`。游戏仅面向竖屏手机；图鉴是独立的可滚动阅读页面。

## 规则与数据的权威来源

设计文档规定体验和规则。运行时的静态数值来自 `src/game/data/`；图鉴的已实装卡片直接读取这些数据。任何对象数值调整都应同步更新对应的 [敌人清单](./敌人.md)、[物品清单](./物品清单.md) 或 [圣遗物清单](./圣遗物清单.md)，并检查图鉴展示。

当前规则、对象清单与未来计划必须分开阅读：规则页和清单页描述当前可游玩的正式内容，[10-roadmap.md](./10-roadmap.md) 记录尚未进入运行时的已确认方向和待确认内容。
