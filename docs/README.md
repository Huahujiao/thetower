# 地牢翻牌冒险：设计文档

这是当前游戏规则、内容和界面的文档入口。运行时静态数据位于 `src/game/data/`；规则或数值改变时，应同步更新对应文档，并用项目检查脚本验证。

## 产品概览

玩家在由方形卡牌构成的五层地牢中探索八个房间。翻牌会带来敌人、武器、物品、资源或陷阱；玩家在逐格移动、敌人阶段、体力管理和 5 行 × 8 列背包之间做取舍，最终击败第五层的监视者并逃离地牢。

游戏入口为 `/`，图鉴入口为 `/wiki`。主界面面向竖屏手机，图鉴是独立的可滚动阅读页面。

## 规则与数据的权威来源

游戏运行时以 `src/game` 为准，`src/legacy` 仅保留历史架构，不属于当前入口。图鉴的已实装卡片直接读取静态数据定义。

当前版本移除了左右手、装备栏、有效行动计数、武器耐久、磨刀石、最后一击、武器损毁和敌人拦截。玩家体力开局为 10；每移动一格回复 1 点，使用物品回复 1 点，攻击消耗 2–5 点；翻牌不消耗体力。旧存档不做迁移，版本不匹配时按 [08-technical.md](./08-technical.md) 的规则处理。
