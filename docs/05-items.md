## 物品协同示例

下表只是玩家可能形成的配合，不是游戏内的套装清单或激活判定。每件物品按自己的条件独立生效。背包四向相邻仅约束明确写有相邻条件的效果；改变位置后立即重算。第二批新增物品已配有临时图标。

| 思路 | 可组合的独立效果 |
| --- | --- |
| 护甲导流 | 防具供甲、导流线蓄势、任意接线武器消耗；盾芯与分叉接头分别增加护甲和连接范围。 |
| 换武接力 | 回旋斧击杀提供换武增益，弹簧降低相邻武器击杀后的换武费用，接力徽记让任意有效命中也提供小额换武增伤。 |
| 护甲攻防 | 城壁剑有甲增伤并花甲；木盾补甲，盾芯放大补甲，回甲刻印返还攻击花掉的护甲。 |
| 属性轮换 | 换相指针识别任意灼热、枯萎、沉溺武器的有效命中顺序；三相轮在带齐三种属性时改变克制倍率。 |
| 金币储备 | 钱秤与拾金钩增加收入，铸币剑在金币达到12时增伤，交易券和账本各自提供折扣。 |
| 背包留白 | 断岳槌四向留白加伤，空匣印按空格降费，断刃秤在单武器时加伤，重腕护符按重武器留白降费。 |
| 移动反击 | 潮步刃移动后增伤；旅者骨牌、步痕靴和回身盾分别提供费用、伤害及护甲收益，均适用于符合自身条件的武器。 |
| 距离控制 | 瞄准镜为相邻弓加射程，测距盘奖励相邻弓最大射程命中，稳弦扣补偿近距离攻击。 |
| 击退碰撞 | 锁链与裂骨钉分别增强相邻长柄武器的击退碰撞；锁魂枪自带碰撞伤害。 |
| 中毒蓄势 | 毒囊使相邻武器附毒，续毒瓶延长这种毒，蚀时漏斗将毒伤转为下一次任意武器攻击的伤害。 |
