# 怪物牌（共 15 张）

> 怪物翻出后留在场上，不立即攻击。玩家行动若不直接攻击它，则它在玩家行动后反击一次。
> 伤害 = 怪物实际攻击力（含污染/狂暴/环境/减速/情绪修正，见《核心机制》战斗系统；当前版本无护甲机制）。
> 弱点类型对应武器克制：劈砍→腐化血肉，穿刺→岩石甲壳，钝击/元素→灵体（克制系数见《核心机制》）。

## 出现楼层规则

| 层级 | 出现楼层 | 说明 |
|------|----------|------|
| 一阶 | 第 1~2 层 | 基础威胁 |
| 二阶 | 第 2~4 层 | 中等威胁 |
| 三阶 | 第 4~6 层 | 高威胁，需武器成型 |
| 精英 | 第 6 层 | 高掉落，稳定产出 |
| Boss | 第 7 层 | 本层唯一核心目标 |

### Boss 层特殊规则
- 第 7 层为 Boss 层，牌堆较小（5×5），**无钥匙碎片、无出口牌**——击杀黑塔之主即通关。
- Boss 在场时，玩家翻牌后 Boss 攻击照常结算；玩家攻击 Boss 当回合只受 Boss 反击。
