# 图鉴页面

## 入口与用途

图鉴路由为 `/wiki`。它用于浏览游戏内容，并提供统一、可读的详情卡片设计。顶部提供返回地牢按钮，标签页使用 URL 哈希保存当前分类：

- `/wiki#enemies`
- `/wiki#weapons`
- `/wiki#relics`
- `/wiki#items`

## 标签页

| 标签 | 已实装数据来源 | 卡片关键字段 |
| --- | --- | --- |
| 敌人 | `catalog.json` 的敌人与首领 | 生命、普攻、射程、初次行动延迟、普攻冷却、主动技能及其基础冷却、属性、行为、特性、经验与掉落。 |
| 武器 | `catalog.json` 的 `weapons`、`enemyLoot` 武器与 `merchantWeapons` | 类别特效、最后一击、攻击、射程、耐久、属性与占格；所有武器均为单手。 |
| 圣遗物 | `relics.js` | 获得与激活规则、准确效果；若未来存在主动圣遗物，额外显示技能与冷却。 |
| 物品 | `catalog.json` 的消耗品与敌人专属掉落物（非武器） | 恢复、护甲、下一击增益或耐久修复、出现层与占格。 |

图鉴卡片应优先展示可用于决策的字段，并使用清晰的标题、类型标签、属性字段和内容色调。它与游戏内的长按详情卡片使用同一套视觉语言。

## 内容状态

图鉴必须清楚区分两种状态：

- **已实装**：实线边框与正常饱和度，直接来自运行时静态数据，并会在游戏中出现。
- **待确认／未实装**：虚线边框、不同状态色与降低的视觉饱和度；包括尚待确认的候选和已确认但暂缓实现的内容，均不得进入地牢生成、奖励、商人货架或战斗规则。

## 待确认内容

以下概念目前仅在图鉴中展示：

| 分类 | 候选／暂缓对象 | 状态 |
| --- | --- | --- |
| 敌人 | 追猎者、观望者、不灭监视者 | 待确认 |
| 圣遗物 | 回声罗盘、门铭余温 | 待确认 |
| 圣遗物 | 邻域换位、敌位换位 | 已确认效果，暂缓实现 |
| 物品 | 烟幕瓶、探路粉 | 待确认 |

候选卡展示可讨论的规则与初步数值，不进入地牢生成、奖励、商人货架或战斗规则。

候选内容与其他未来功能的状态以 [10-roadmap.md](./10-roadmap.md) 为准。
