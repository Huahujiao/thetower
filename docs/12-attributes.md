# 属性与卡背

敌人、武器和物品均具有一种属性，并以属性循环决定战斗克制关系。

## 属性克制

属性共有四种，循环克制如下：

> 灼热 → 黏液 → 结晶 → 湍流 → 灼热

| 属性 | 卡背暗纹颜色 |
| --- | --- |
| 灼热 | 红色 |
| 黏液 | 绿色 |
| 结晶 | 黄色 |
| 湍流 | 蓝色 |

## 卡背提示

卡背使用统一暗色底纹，以属性颜色的暗纹区分属性；卡背不显示文字，也不直接显示卡牌内容。

空格、金币、楼梯等中性格子不具有实际属性；生成时仍随机获得四种属性卡背之一。其作用是避免玩家通过卡背将某张牌判断为安全牌。边界门不属于棋盘格，因此没有属性卡背。

同一层中的中性格子可具有不同卡背。例如，一个金币可显示灼热卡背，另一个金币可显示黏液卡背。

## 卡面显示

有属性的卡牌在右上角显示属性名称，文字颜色对应红、绿、黄、蓝属性。

## 伤害结算

攻击属性克制目标属性时，伤害为基础伤害的 ×1.6；攻击属性被目标属性克制时，伤害为基础伤害的 ×0.65；同属性或不构成克制时不修正伤害。武器以自身属性参与此结算。若对应手已选择该武器属性的属性适应，则克制倍率为 ×1.8，受制倍率为 ×0.8；双手武器只要任一只手适应该属性即可生效，两个适应不会叠加。
