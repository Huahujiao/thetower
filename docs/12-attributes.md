# 属性与卡背

敌人与武器以属性参与主攻击克制；部分防具、材料、圣遗物和消耗品也有属性标签，但自身不参与克制倍率。卡背仍仅用颜色提示敌人与武器；防具不在地面生成，因而没有卡背。其他地面对象使用中性灰白卡背。

## 属性克制

属性共有三种，循环克制如下：

> 灼热 → 枯萎 → 沉溺 → 灼热

| 属性 | 卡背暗纹颜色 |
| --- | --- |
| 灼热 | 红色 |
| 枯萎 | 黄色 |
| 沉溺 | 蓝色 |

## 卡背提示

卡背使用统一暗色底纹，以属性颜色的暗纹区分属性；卡背不显示文字，也不直接显示卡牌内容。

陷阱、非武器物品、金币、钥匙机关、商人、空格和楼梯等对象不使用属性卡背提示，统一使用灰白色卡背主题。边界门不属于棋盘格，因此没有属性卡背。每种颜色还分为可翻和不可翻两种明暗状态，共 8 种卡背状态。

## 卡面显示

有属性的敌人立牌保持红色危险主题，并在红色外轮廓内叠加半透明的属性色细轮廓，头部圆环也使用同一属性色；商人不使用属性色，仍保持金色立牌轮廓。地面武器卡面用属性色显示纯攻击力数字，不再在右上角重复显示属性名称；射程、类别和占格等信息可在详情面板查看。需要查看完整属性文字时，可长按棋盘对象打开顶部详情面板。

## 伤害结算

攻击属性克制目标属性时，伤害为基础伤害的 ×1.6；攻击属性被目标属性克制时，伤害为基础伤害的 ×0.65；同属性或不构成克制时不修正伤害。仅武器主攻击参与此倍率。其他物品的属性是效果条件或标签，碰撞、反伤、爆炸、中毒不参与倍率。
