# 属性与卡背

战斗克制只使用敌人与武器的属性。当前 `catalog.json` 中的消耗品和敌人专属掉落仍保留属性字段，图鉴和已翻开卡面会显示这些字段，但它们不参与战斗克制；其卡背仍使用中性灰白主题。

## 属性克制

属性共有三种，循环克制如下：

> 灼热 → 枯萎 → 沉溺 → 灼热

| 属性 | 卡背暗纹颜色 |
| --- | --- |
| 灼热 | 红色 |
| 枯萎 | 黄色 |
| 沉溺 | 蓝色 |

## 卡背提示

卡背使用统一暗色底纹，以属性颜色的暗纹区分属性；卡背不显示文字，也不直接显示卡牌内容。

陷阱、物品、金币、钥匙机关、商人、空格和楼梯等中性对象不具有用于卡背提示的属性，统一使用灰白色卡背主题。边界门不属于棋盘格，因此没有属性卡背。每种颜色还分为可翻和不可翻两种明暗状态，共 8 种卡背状态。

## 卡面显示

有属性的卡牌在右上角显示属性名称，文字颜色对应红、黄、蓝三种属性。当前数据中带有属性字段的物品也会按上述规则显示名称，但卡背仍保持中性灰白。

## 伤害结算

攻击属性克制目标属性时，伤害为基础伤害的 ×1.6；攻击属性被目标属性克制时，伤害为基础伤害的 ×0.65；同属性或不构成克制时不修正伤害。武器以自身属性参与此结算。若对应手已选择该武器属性的属性适应，则克制倍率为 ×1.8，受制倍率为 ×0.8；当前选中的单手武器只检查其对应手的适应属性。
