# 升级、奖励与商店

## 升级天赋

击杀敌人获得经验；升级从最多4个可解锁天赋与“强健体魄（最大生命+2，可重复）”中选择。保留前置树，改为换势、守御、调和、求生四条路线，共20节点。

## 房间奖励与物品来源

首次进入分支房或首领房会提供房间奖励，可选择或跳过。精英路线固定提供圣遗物选择，补给路线固定提供补给选择；首领房使用三次补给、一次圣遗物的循环奖励袋，在进入首领战前发放。入口不弹房间奖励。补给可提供基础武器、防具或消耗品。开局先从三个圣遗物候选中选一个。前三章首领提供经验；升级选项在击杀及其死亡／自爆动画完成后出现。

- 房间地面初始随机物品包含基础武器和消耗品；普通地面随机格不会生成防具，材料、合成武器也不作为初始地面物品。
- 指定敌人的物品掉落在材料与对应防具之间二选一，沿用该敌人的掉落概率；死亡掉落留在原地，需要拾取。生成物不提供经验或战利品。
- 防具也可从普通商人和房间补给获得；普通地面随机格不会生成防具。普通商人货架可销售全部 65 种物品，其中第四格固定从材料池抽取；收藏家提供圣遗物选择。购买、出售和刷新货架不推进回合。
- 圣遗物通过开局、房间奖励和商人获取，在背包中占 1 格；同名效果不叠加，没有数量超载限制。圣遗物效果清单见 [05-items.md](./05-items.md)。
- 六个合成配方和操作成本见 [04-inventory.md](./04-inventory.md)。
- 补给和圣遗物奖励根据背包现有物品的宽泛效果标签（如护甲、金币、弓、毒）优先推荐一件尚未拥有的相关物品；楼层门槛仍生效。标签只影响推荐，不决定物品效果是否生效。玩家可选其他奖励或跳过。
- 烬钥剑、腐环匕、潮尺弓依次在第1、2、3层开放；普通随机武器、商店和推荐补给均遵守楼层门槛。导流线和分叉接头不在初始地面随机池，可经普通商店或相关标签的补给推荐获得。合成回旋斧会消耗弹簧材料，若还想获得弹簧的相邻效果，需要再次取得弹簧。
- 钱秤拾取每堆金币额外+1；交易券使普通商人货品减价1；折价账本使普通商人刷新货架费用减少2，最低均为1金币。两件物品各自生效，均不改变收藏家的圣遗物选择或出售价格；商店显示与实际付款采用同一价格计算。
- 测距盘第2层起出现；稳弦扣、裂骨钉、续毒瓶及新圣遗物无额外楼层门槛。新增四种材料不进入初始地面随机池，也不进入现有六种敌人材料掉落，可在普通商店或相关标签的补给推荐中获得。步痕靴、蚀时漏斗可出现在圣遗物奖励、开局候选、收藏家或普通商店。
- 断岳槌、鹰眼弓、锁魂枪和蚀骨刃仍可按既有配方合成，也可从普通商店获得。合成会消耗对应材料；若还想利用材料本身的相邻效果，需要再次取得材料。
