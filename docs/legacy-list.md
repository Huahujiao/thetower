# 圣遗物设计记录

本页保留确认过程中的编号与设计简述；当前实现状态和准确效果以 [圣遗物清单.md](./圣遗物清单.md) 为准。4、21 号效果已确认但暂缓实现。

1. 背包满时1.5倍加成
2. 背包空时3倍加成
3. 攻击折射到身后1格，如果是未翻开的牌则翻开
4. 可将周围8邻域的牌与该小局随机房间替换（已确认，暂缓实现）
5. 每有一张可翻开的牌，加一点加成
6. 可翻开距离为2的牌
7. 翻开敌人牌时，使敌人攻击延迟+1
8. 造成伤害和受到伤害都变为2倍
9. 一回合内每受到1次伤害，回合结束前就回复1点血（例如被多个敌人围攻的情况）
10. 对同一敌人多次攻击伤害递增1点。
11. 每杀死10个敌人，大吼一声，翻开该层所有敌人。（10个敌人计数是跨层累计）
12. 每用坏一把武器，使你的另一把武器增加2点攻击力，优先手中的武器。
13. 攻击回血，按造成伤害的0.3倍，向下取整
14. 每2回合回2血
15. 翻开一张牌时，可以查看其旁边的随机一张牌而不翻开（半透明状态）
16. 每第10次攻击直接将敌人变为其当前血量等额的金币（跨层计数）
17. 【胜利在望】在已发现出口 arrival tile 的情况下，敌人所在位置离出口越近，伤害越高。距离1时+5，距离2时+4，距离3时+3，距离4时+2，距离5时+1。
18. 每杀死一个敌人获得1金币
19. 狂战士：每比最大生命少5点生命，伤害倍率 +0.5，最高 ×5。
20. 满血时伤害倍率为1.5，每少10%的血，减0.1倍率，即半血以下失去加成
21. 攻击后将该敌人交换到随机位置，如目标位置有牌，交换位置时不翻开该牌（已确认，暂缓实现）
22. 每当一把武器用坏时，对一名随机敌人造成3点伤害，如果当前敌人未死亡，优先当前敌人
23. 每当实际回血时，使手中随机一把已装备武器攻击 +1。
24. 拆弹专家，翻开陷阱牌时，无视其效果，并回复5点护甲，5点生命
25. 耐久度低于一半的武器，攻击时溅射一圈范围，目标的八邻域
26. 每3回合将一把随机武器放入行囊中
27. 绝不手软：敌人生命不高于一半时，对其伤害 ×1.5。
28. 每次攻击获得3点护甲
29. 敌人死亡时爆炸，对其八邻域造成2点伤害，如果有未翻的牌，则翻牌
30. 每持有10金币，加1攻击力
31. 背包中有7把及以上武器时，伤害乘以1.7倍
32. 攻其不备，当敌人的普攻和技能都处于冷却中时，攻击它伤害+5
33. 反制余烬：房间内任何敌人施放主动技能时，玩家获得 3 点护甲
34. 及时处理：击杀“主动技能冷却为0”的敌人时，回复 1 点生命并获得 1 金币。
35. 钥匙回响：拾取钥匙时，揭示对应门 arrival tile 周围的 8 邻域卡牌。
36. 同调余响：以属性克制击杀敌人时，当前武器恢复 1 点耐久。
37. 学徒刻印：每层首次击杀一种敌人时，击杀手的掌控 +1，如果使用双手武器，则左手掌控+1。每层的同一种敌人不重复触发
38. 绝境保险：每个房间一次，受到致命伤害时保留 1 点生命，并获得 5 点护甲。适合做稀有保命圣遗物。
39. 清道协议：在击败一个敌人时，如果当前房间内没有其他已翻开的敌人，则随机翻开一张未翻牌。
40. 门槛封印：每个房间首次翻开敌人时，该敌人行动延迟+1；其主动技能冷却永久+1。
41. 先锋一击：每个房间的第一次攻击不消耗武器耐久，且对尚未行动过的敌人伤害 +2。
42. 先锋赏金：每个房间首杀时，获得 2 金币并回复当前武器1点耐久。
43. 连击战意：本房间每击败一名敌人，获得 1 层战意，最多 3 层；每层使攻击 +2。拾取任意物品、金币或资源牌时，失去一层战意；离开房间清空。
44. 残局透镜：房间仅剩最后一名敌人时，立刻翻开并标记它；它的主动技能冷却 +1。
45. 末战誓约：房间最后一名敌人受到的伤害 +30%，但其对玩家造成的伤害也 +30%。适合做高风险收尾型圣遗物。
46. 安魂铁砧：房间清场时，修复装备中耐久最低的武器2点
