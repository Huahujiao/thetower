# 旧版圣遗物

本页保留本次天赋／圣遗物重构中移除或正式放弃的旧版圣遗物，供后续寻找设计灵感。它们不属于当前奖励池、商店或图鉴；历史效果仅作为设计记录，不再视为当前规则。

其中 4、21 号在当前代码中已经不存在，本页保留它们是为了完整保存旧版设计记录；其余 8 件已从运行时代码中删除。
