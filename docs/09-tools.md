# 图鉴与动画编辑工具

这些工具位于独立路由，不创建根路由的 `GameRun` 或棋盘。游戏规则以 [01-overview.md](./01-overview.md) 起的文档和 `src/game` 为准。

## 图鉴 `/wiki`

图鉴展示当前运行时的敌人、陷阱、武器、圣遗物、天赋和其他物品；分类可由 URL 哈希定位：`#enemies`、`#traps`、`#weapons`、`#relics`、`#talents`、`#items`。它读取游戏的静态定义，不维护另一份提案数据；敌人生命展示与生成时相同的两倍倍率。

| 分类 | 主要数据来源 |
| --- | --- |
| 敌人、首领和武器 | `src/game/data/catalog.json` |
| 陷阱 | `src/game/data/traps.js` |
| 圣遗物 | `src/game/data/relics.js` |
| 天赋 | `src/game/data/progression.js` |
| 其他物品 | `src/game/data/catalog.json` |

图鉴中的物品图像与游戏共享小／中尺寸透明精灵。敌人卡片展示行为、特性、射程和掉落；防具来源包括地面随机物品、指定敌人掉落、商人及房间补给。具体数值以数据模块为准，物品和敌人的阅读版清单分别见 [05-items.md](./05-items.md) 和 [07-enemies.md](./07-enemies.md)。

## 动画编辑器 `/animeedit`

编辑器管理独立角色库，用于绘制关节、骨骼、几何部件或透明贴图，并为待机、移动、攻击、受击、死亡动作编关键帧。角色库与编辑结果自动保存在浏览器 `localStorage`；新增、复制、改名、删除及编辑均支持当前会话内撤回。初次打开提供空白角色和三个示例角色。部件可临时隐藏，这个显示状态不写入角色数据。

“正面”视图用于编辑；3D 视图使用透视相机、地板格和单角色预览，可单指旋转、双指缩放。骨架和网格开关在两种视图都可使用：骨架控制关节点与骨骼线，网格控制部件几何体的显隐；关闭网格后，3D 地板格仍保留，便于观察骨架的空间位置。贴图页维持无骨架的外观预览。两种视图读取同一份角色、部件和动作数据，均从正 Z 方向观察，Z 越大越靠近观察者。旧角色数据会按编辑器的数据版本迁移。底部固定工具区提供骨架、部件、贴图与动作编辑；贴图可选 `contain` 或 `cover`，也可恢复纯几何外观。

`/animepreview` 保留只读预览路由。编辑器数据和预览资源不参与游戏本体的回合与战斗结算。角色工具与游戏临时符号动画的边界见 [10-technical.md](./10-technical.md)。
