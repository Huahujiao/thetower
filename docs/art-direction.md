# 整体美术方向：雾光淡彩东方志怪

## 一句话

**高明度、低饱和、冷灰底，局部暖光；暗黑是叙事气质，不是画面曝光。**

不选“全局明亮扁平手绘”，也不选“整体暗黑 + 局部照明的地下城”。保留 3D 棋盘的盆景感，用柔光、雾气和皮影剪影承载东方志怪氛围，同时保证手机小屏上的卡牌信息可读。

## 明度层级

| 层级 | 作用 | 目标 |
| --- | --- | --- |
| 环境层：远山、雾、背景 | 空气透视、留白 | 高明度、低对比，不压成黑 |
| 舞台层：地板、平台、卡背 | 承载棋盘 | 中高明度、低饱和；地板不能是画面最暗处 |
| 表演层：角色、敌人、物品、特效 | 视觉焦点 | 最高对比，允许局部高光/暖色 |
| UI 层：HUD、按钮、血条、背包 | 信息与操作 | 文字高对比、面积小；不要比棋盘更亮 |

检验方法：截图转灰度后，**地板不应是最暗的，卡背不应是最亮的，角色和可交互物应最先被看到**。

## 光线

- 主光：左上方柔和暖光，负责体积和投影。
- 补光：冷色环境光 + IBL，把暗部抬起来，保证所有格子可读。
- 阴影：短、软、贴地；接触阴影可以黑，但不把整个场景压暗。
- 暗场只作为标点：普通房间保持中高明度，Boss 房/事件房才局部压暗并用火光/月光引导。
- 不用全局暗角把画面压黑；暗角只做轻微构图收束。

## 材质与色彩

- 石材、卡牌、纸符、皮影统一走哑光、低高光、手绘纹理；避免写实 PBR 金属高光。
- 卡背保持浅浮雕，不做石刻；属性色是低饱和标记，不是高纯度红黄蓝。
- 冷灰绿/青灰是底色，暖琥珀、朱砂只用于光、火、金币、危险和可交互物。
- 敌人和物品是表演层，可以比环境更饱和，但要有统一的色温和接触阴影。

## 第一轮落地（2026-10-19，/arttweak vertical slice）

- 渲染保留 Neutral 色调映射，曝光 1.04；主光 2.55、IBL 0.30。中途试过 AgX，但它把整盘抬成一层白霜，已回退。环境光/半球光在 IBL 加载后关闭，只作为失败回退，不再负责画面亮度。
- 地板色板整体提亮但仍保留色阶，石面材质色乘数从 `0xc0d4db` 改为 `0xd8e6e8`；地板对 IBL 的接收倍率从 `0.22` 提到 `2.5`（`envMapIntensity` 约 0.75），让被栏杆阴影盖住的地板也保持明亮冷灰蓝。
- 卡背法线强度从 1.15 降到 0.65；属性卡背低饱和处理保持 `BACK_TONE_SATURATION=.86`、`BACK_TONE_EXPOSURE=1.00`，色相不变。
- 贴片阴影改为纯黑、放大并按主光方向右下偏移；物品/金币也有独立接触阴影。
- /arttweak 场景只保留轻微冷边缘暗角，不再叠加暖白中心光，并压低主按钮和血条的饱和度。

## 尚未覆盖

- 其他楼层/主题的照明与色板；普通游戏 HUD 的全局样式。
- 敌人/物品插画的统一色彩分级。
- 手机 GPU 上的 Neutral 色调映射与 CSS 叠层性能。
- 新场景、新敌人、新卡面插画仍需图像生成工具或画师；脚本只负责现有素材的调色、材质、变体和后期统一。
