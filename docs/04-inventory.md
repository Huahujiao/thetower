# 背包、物品与合成

## 已确认的共同规则

- 背包固定8列×4行。相邻按物品实际占用格子的上下左右判定，不计斜角；旋转后实时重算。
- 旋转是拖拽时的摆放预览，本身不推进回合。成功把物品放入背包格子（包括旋转后放回原位置）、移入暂存区或丢弃物品，各推进1个全局回合，结算状态与敌人阶段，不恢复体力。一次替换中，被替换物品自动进入暂存区，不另计回合。暂存区是自由画布，区内移动或旋转不推进回合；选择、取消和失败放下也不推进回合。商店中整理背包同样遵守此规则。
- 所有防具均为被动，不能主动使用。护甲先吸收普通伤害，保留跨房间积累且不设上限；防具以持续减伤、补足护甲或战斗节奏触发为主。
- 消耗品使用、成功合成各推进1回合，不额外恢复体力；体力药实际恢复3。普通移动、翻牌、拾取、交互仍恢复1体力。
- 武器只具有其条目列出的特效，不附带旧类别统一特效。合成不继承未列出的基础武器效果。
- 主攻击伤害：基础攻击与固定加成相加，再乘属性和地形倍率，向下取整，允许为0，然后结算目标防御。
- 三属性循环：灼热→枯萎→沉溺→灼热；克制×1.6，被克制×0.65。物品的其他属性只作为标签或条件。
- 近战射程1使用八邻域距离，射程2以上使用曼哈顿距离，不计算遮挡。最大射程按当前全部加成计算；寻路也检查到达格上的射程。
- 体力加费与减费相加，最终攻击费用最低1。先支付，再结算击杀返还，体力上限10。
- 计数优先使用跨房间延续的“每第N次攻击/受击”；与房间绑定的效果只允许每房间一次。房间中途获得轻甲不会补发进房护甲。
- 同名防具、材料和圣遗物效果不叠加。不同来源加成可以叠加；同一来源“下一次”增益只保留一份。
- “其他武器”按具体物品实例区分，包括同型号的另一把武器。
- 行为序列按实际世界行动记录；自动接近敌人也算移动。背包选中不打断序列，整理、合成、使用物品会打断连续移动。
- 纯移动不产生护甲、生命或可累积增益。稳步需要移动后命中；旅者骨牌奖励移动攻击，同时提高连续攻击的体力消耗。传送与敌人拉动不算主动移动。
- 三相轮检查背包是否同时持有三种属性武器，直接改变克制倍率，不维护房间计数。
- 仅主攻击最终击杀触发武器、天赋和圣遗物的击杀收益。爆炸、碰撞、反伤、中毒不触发这些收益，也不参与属性倍率。
- 毒囊相邻武器造成正伤害时附毒；中毒每敌人阶段开始前造成1伤害，持续2次，不叠加，重施刷新为2次。附加当回合会结算第一次。
- 碰撞只伤害被击退者。房间边界视为墙；未翻牌或非敌人物品阻止位移但不造成碰撞伤害。
- 断岳槌的留白检查整个实际形状外缘；自身占格和背包边界不算其他物品。
- 城壁剑攻击前有任意护甲即加伤，结算后最多扣2护甲。这种主动消耗不触发“被敌人打空护甲”。
- 腐藤甲只减免敌人普通攻击，避免中毒或狂战酒被免除；狂战酒自伤绕过护甲且可致命。
- 下一击增益可以跨房间保留，消耗发生在主攻击前；该攻击新产生的增益留给之后的攻击。圣遗物或弹簧产生的待用增益需要仍持有其来源。

## 合成与获得途径

合成按钮随时可打开（探索与商店阶段），面板只列出背包拥有两种原料的方案，每行显示 A+B=C。长按三个物品中的任意一个可查看详情。成品占位不足时按钮禁用；失败不消耗原料或回合。成功消耗对应两个实例，将成品放入背包并推进1回合，无金币费用。第一版无二次合成。

| 基础武器 | 材料 | 合成武器 |
| --- | --- | --- |
| 沉银守剑 | 盾芯 | 城壁剑 |
| 焦痕手斧 | 弹簧 | 回旋斧 |
| 枯骨匕 | 毒囊 | 蚀骨刃 |
| 炭纹长枪 | 锁链 | 锁魂枪 |
| 沉木短弓 | 瞄准镜 | 鹰眼弓 |
| 枯岩重锤 | 配重块 | 断岳槌 |

- 地面随机物品：基础武器、防具、消耗品，类别权重约为58%／17%／25%；材料与合成武器不进入初始随机池。第1和第3章必经整备房另保证放置一件随机防具。
- 敌人物品掉落：原有六种合成材料与对应敌人的防具共享原掉落概率并二选一；新增材料通过商店或相近效果的定向补给获取。召唤物不掉落。敌人不掉落武器或圣遗物。
- 防具可从地面随机物品、指定敌人掉落、普通商店和房间奖励获取。
- “地面不生成材料”指不作为房间初始随机物品；敌人死亡掉出的材料仍留在死亡位置，需拾取入包。
- 普通商店可出售全部65种物品，包括材料、合成武器和圣遗物。收藏家继续提供圣遗物选择服务。
- 圣遗物通过开局、房间奖励和商店获得；同名唯一，无“超过五件全部失效”的限制。
- 物品只按各自写明的资源、行为、类别和相邻条件生效，不检查固定组合名单。相邻按实际占用格子实时重算；移走某件物品只失去该件提供的效果。导流线、测距盘和蚀时漏斗的待用蓄势在对应来源离开背包后清空。示例协同见 [05-items.md](./05-items.md)。

完整数值见 [05-items.md](./05-items.md)，奖励与商店来源见 [06-progression.md](./06-progression.md)。

## 触屏整理与暂存区

游戏面向手机竖屏触屏。轻点已占用格选中物品用于战斗或使用；长按 150 ms 查看详情，继续移动超过 18 px 后进入拖拽。长按中的第二根手指每次新触碰将物品顺时针旋转 90°。不规则物品的空洞格不能作为触摸目标。

拖拽时，上方区域的红色丢弃区占 25%，蓝色暂存自由画布占 75%。暂存物品按背包格尺寸显示，可在画布内自由移动或旋转，即使相互重叠也不产生回合；自动暂存优先寻找不重叠的位置。暂存区没有固定格子规则，也没有“清空暂存区”的额外回合费。

放入背包时，以物品可见形状的中心吸附到最近的落点。绿色预览表示可放，黄色表示会替换占用物并使其自动进入暂存，红色表示无效。一次成功放下、移入暂存或丢弃分别消耗一个全局回合；替换过程只计玩家的一次操作。单纯旋转、取消、无效落下、触摸中断、窗口失焦均不计回合。旋转后成功放回原位置仍计一次放下操作。
