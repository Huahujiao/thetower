# 《回合相关机制》（临时讨论稿）

> 这是一份用于讨论回合节奏、攻击计数和各种“下一次／第 N 次”效果的临时清单。
>
> 数据基准：当前 `src/game` 运行时，不包含 `src/legacy` 中的旧版机制。
>
> 更新日期：2026-09-04

## 1. 三种回合的正式定义

当前代码使用 `src/game/core/turns.js` 中的 `TurnLedger` 递进维护三种计数。这里的“回合”不是一个单一数字：

| 层级 | 运行时字段 | 递进规则 | 适用方向 |
| --- | --- | --- | --- |
| **攻击计数** | `run.attackCount` | 有效主攻击发出 `attack:started` 时 +1。 | 攻击次数、攻击序列和“下一次攻击”。 |
| **行动计数** | `run.actionCount` | 有效的非纯移动行动完成时 +1；攻击包含在内。 | 玩家有利的冷却、行动次数和行动序列。 |
| **全局回合** | `run.globalTurn`；兼容旧代码的 `run.turn` | 每次有效行动或纯移动完成时 +1。 | 敌人阶段、玩家有害的持续效果和总进度。 |

三者的包含关系是：

```text
攻击计数 ⊂ 行动计数 ⊂ 全局回合
```

也就是：一次攻击同时推进三层；一次其他有效行动推进行动计数和全局回合；一次纯移动只推进全局回合。全局回合可理解为“行动计数 + 纯移动次数”。多格路径只算一次对应的推进，不按步数增加。

当前代码使用 `turnKind` 明确推进层级：

| `turnKind` | 推进的计数 | 当前用途 |
| --- | --- | --- |
| `attack` | 攻击、行动、全局 | 有效主攻击。 |
| `action` | 行动、全局 | 翻牌、拾取、使用物品、磨刀石、装备／卸下、成功进入商人、成功进门。 |
| `movement` | 全局 | 纯移动，或被拦截后未完成目标行动的移动。 |

因此，后续规则应按效果方向选择层级：玩家有利的冷却和奖励通常监听行动计数或攻击计数，不能让纯移动白白推进；玩家有害的中毒、灼烧或其他“每回合”效果才使用全局回合。

当前即时操作（背包整理、丢弃、商人面板、奖励和升级选择）不推进三种计数。成功使用药水、护甲药剂、增益物品／攻击符文和磨刀石属于有效行动，统一使用 `turnKind: action`；仅选择磨刀石和选择目标的过程不推进计数。

## 2. 计数事件与攻击事件

攻击相关事件的顺序大致为：

```text
attack:started
  -> 主目标伤害结算
     -> 若主目标此时最终死亡，立即发出 enemy:killed
  -> attack:primary-hit / attack:hit
  -> attack:primary-kill（若主目标被击败）
  -> 斧溅射／长柄碰撞／弓贯穿／属性天赋等后续效果
     -> 后续效果造成最终击杀时，再发出 enemy:killed
  -> attack:enemy-defeated（若主攻击直接击败目标）
  -> weapon:broken（若最后一击损毁武器）
  -> attack:resolved
  -> 以 attack 类型推进三种回合，进入敌人阶段
```

其中 `enemy:killed` 可能由攻击之外的来源触发；它在敌人从房间移除的瞬间发出，所以主攻击击杀时会早于 `attack:primary-hit`。`attack:enemy-defeated` 只对应玩家主攻击直接击败目标；斧溅射、弓贯穿、死亡爆裂等后续伤害只会产生 `enemy:killed`，不会产生这个事件。

## 3. 全局回合流程

### 3.1 会推进行动计数和全局回合的操作

| 操作 | 攻击计数 | 行动计数 | 全局回合 | 敌人阶段 | 备注 |
| --- | ---: | ---: | ---: | --- | --- |
| 移动到已翻开的空格 | — | — | +1 | 正常执行 | 一次点击可能沿多格路径移动，但整次操作只算一次纯移动。 |
| 翻开未知卡牌 | — | +1 | +1 | 正常执行 | 先移动到目标邻近位置，再翻牌；陷阱会在敌人阶段前立即触发，并保留到一个后续全局回合计数完成后移除。 |
| 攻击敌人并成功发动 | +1 | +1 | +1 | 正常执行 | 角色会先移动到武器可命中的位置。 |
| 拾取物品、金币、钥匙或圣遗物 | — | +1 | +1 | 正常执行 | 接近途中被拦截时只算移动。 |
| 使用生命药水、护甲药剂或增益物品／攻击符文 | — | +1 | +1 | 正常执行 | 物品成功消耗后才推进；使用物品不能绕过敌人阶段。 |
| 使用磨刀石并指定目标武器 | — | +1 | +1 | 正常执行 | 先点击磨刀石只进入选目标状态，指定武器后才推进。 |
| 装备或卸下武器 | — | +1 | +1 | 正常执行 | 背包空间不足导致操作失败时不推进。 |
| 走到商人并开始交互 | — | +1 | +1 | 正常执行 | 接近途中被拦截时只算移动。 |
| 通过门进入下一房间 | — | +1 | +1 | 跳过 | 成功进入下一房间时跳过原房间的敌人阶段。 |
| 目标行动被拦截 | — | — | +1 | 正常执行 | 已发生移动和拦截反击，但未完成目标行动。 |

一次移动、翻牌、拾取、交互或攻击的多格路径仍然只推进一次对应计数；路径上的每一步都可能触发伏击或拦截检查。

### 3.2 不推进三种计数的操作

| 操作 | 当前行为 |
| --- | --- |
| 选择生命药水、护甲药剂或增益物品／攻击符文 | 只改变选中状态，不推进计数；实际使用时按一次有效行动处理。 |
| 整理、移动或旋转背包物品 | 不进入敌人阶段。 |
| 选择或取消选择背包物品、装备栏武器 | 不进入敌人阶段。 |
| 丢弃背包物品或已装备武器 | 不进入敌人阶段。相关圣遗物效果立即处理。 |
| 商人面板中的购买、刷新、出售、圣遗物购买和配置 | 不推进三种计数；商人交互开始时的那一次进入交互才推进。 |
| 关闭商人面板 | 不推进三种计数。 |
| 选择或跳过房间奖励 | 不推进三种计数。 |
| 选择升级天赋或强化体格 | 不增加计数；升级阶段暂停探索。 |

### 3.3 `_endTurn()` 的执行顺序

正常情况下，一次推进全局回合的操作完成后：

1. `TurnLedger` 按 `turnKind` 递进计数。
2. 发出 `turn:advanced` 和 `turn:started` 事件。
3. 结算玩家的全局回合状态，例如毒雾陷阱的中毒伤害和敌人施加的燃烧伤害。
4. 处理假死敌人的复活倒计时。
5. 当前房间中已翻开的敌人按翻开顺序行动。
6. 发出 `turn:ended` 事件。
7. 持久化并刷新界面。

如果玩家在敌人阶段死亡，`turn:ended` 不会继续发出。成功进门会使用 `skipEnemyPhase: true`，因此会推进行动和全局回合并发出开始／结束事件，但不执行原房间的敌人行动。

## 4. 按全局回合推进的机制

### 4.1 敌人行动延迟

每名敌人有 `actionDelay`：

- 翻开敌人时使用其 `initialActionDelay`。
- 每次敌人阶段轮到它时，若延迟大于 0，只减少 1，不移动、不攻击。
- 延迟为 0 后，才进入行为和普通攻击判断。
- 圣遗物“迟滞火种”会在翻开敌人时额外增加 1 回合延迟。
- 它监听 `enemy:revealed`：玩家翻牌、警报唤醒、声响陷阱或其他使用统一翻敌人流程的效果都会触发；伏击直接现身不经过该事件。
- 沉溺天赋“深陷”在沉溺克制但未击杀目标时，使该目标行动延迟 +1；每名敌人最多触发一次。
- 长柄天赋“拒马”发生碰撞时，使目标行动延迟 +1。
- 声响陷阱批量翻开的敌人会被设置至少 1 回合行动延迟，并跳过当前敌人阶段。

### 4.2 敌人普通攻击冷却

敌人有 `attackCooldown` 和 `attackCooldownMax`：

- 普通攻击冷却为 1：每个可行动回合都可以攻击。
- 普通攻击冷却为 2：攻击后等待 1 个敌人回合，再次攻击。
- 普通攻击冷却为 3：攻击后等待 2 个敌人回合，再次攻击。
- 代码实际写入的等待数为 `attackCooldownMax - 1`。
- 敌人处于行动延迟中，或因声响陷阱被跳过时，不会推进自己的普通攻击冷却。
- 追击敌人如果移动后进入射程，可以在同一个敌人回合内攻击；驻守敌人不主动移动。

### 4.3 复活倒计时

还魂侍卫第一次生命归零时进入 `downed` 假死状态：

- 假死目标仍占据原格，但不再进入正常敌人行动列表。
- `reviveTurns` 初始为 2。
- 每次正常 `_endTurn()` 开始时减少 1。
- 倒计时归零前再次攻击假死目标，会直接完成最终击杀。
- 没有被补刀时，目标恢复满血，重置初始行动延迟和普通攻击冷却。
- 复活完成后才重新参与敌人阶段。

### 4.4 每个敌人回合的再生

苔藓巨像具有再生 1：

- 每次轮到它行动前，如果当前生命低于最大生命，恢复 1 点生命。
- 再生后才执行驻守、追击等行为和普通攻击判断。
- 声响陷阱批量翻出的敌人会被跳过本次敌人阶段，因此不会触发再生；行动延迟不会阻止再生，因为再生在 `stepEnemy` 之前结算。

这属于“每个敌人行动回合”机制，不是无条件的全局每回合回血。

### 4.5 回合结束恢复：回响软膏

圣遗物“回响软膏”使用全局回合事件：

- 当前全局回合内玩家每受到 1 次有效伤害，记录 1 次受击。
- 全局回合结束时按本回合记录的受击次数恢复等量生命。
- 一个全局回合内受到多名敌人攻击时会累计多次。
- 只记录经过格挡后仍大于 0 的受击；即使最后完全由护甲吸收也会计入，伤害被减为 0 才不计入。
- 玩家在敌人阶段死亡时不会进入正常的回合结束恢复流程。

### 4.6 毒雾陷阱的中毒

毒雾陷阱使用全局回合计数，而不是行动计数：

- 翻开毒雾陷阱时只记录玩家中毒 3 个全局回合，不在翻牌动作当下造成伤害。
- `_endTurn()` 推进全局回合后，结算一次中毒状态；因此翻开后的下一次全局回合是第 1 次伤害。
- 每次结算造成 2 点生命伤害，共结算 3 次；伤害使用 `ignoreArmor`，不消耗护甲。
- 纯移动、其他有效行动、攻击和进门都会推进全局回合，因此都可能触发中毒结算。
- 重复触发当前按刷新规则处理：剩余时间和伤害取较大值，不叠加多份中毒状态。

### 4.7 敌人燃烧、死亡中毒与自身行动

- 赤针火蜥、赤轮火鸦和烬咒灯群的普通攻击命中后施加燃烧；当前燃烧持续 2 个全局回合，每回合造成 1 点伤害，正常受到护甲吸收。
- 燃烧在施加攻击后的下一次全局回合开始结算，不在攻击当下额外扣血；与毒雾中毒一样，状态计时由全局回合推进。
- 腐囊蟾最终死亡时，如果玩家处于它的八邻域，会施加 2 个全局回合的中毒；每回合 2 点伤害且无视护甲。
- 潮祀母体使用 `ownActionCount` 记录自身实际移动或普通攻击次数，不把行动延迟、冷却等待和纯玩家移动算进去；每 3 次自身行动尝试召唤 1 只潮影，场上最多保留 2 只。
- 牵引在普通攻击命中后处理；疾行敌人最多移动 2 格，确实移动 2 格时跳过当次普通攻击。上述敌人行为都发生在当前全局回合的敌人阶段内。

## 5. 按攻击次数或攻击序列计算的机制

### 5.1 跨房间、跨楼层的攻击次数

三层基础计数在本局内持续累计；下面两个圣遗物还保留自己的局部阈值状态，因此它们可以从获得／激活时重新起算，不能简单等同于 `run.attackCount % N`。

| 圣遗物 | 计数条件 | 达到阈值后的效果 | 重置范围 |
| --- | --- | --- | --- |
| 流动兵库 `r-weapon-foundry` | 每发出 `attack:started` 计 1 次攻击。 | 第 3 次时尝试将 1 把随机武器放入背包。 | 跨房间、跨楼层保留；达到 3 次后归零。背包放不下时计数仍然归零。 |
| 炼金脉搏 `r-tenth-alchemy` | 每次有效发动攻击时计 1 次。 | 第 10 次在主攻击伤害结算前，将当前目标直接变为其当前生命值等额金币。 | 跨房间、跨楼层保留；触发后归零。 |

“炼金脉搏”在第 10 次攻击触发后不会再进行普通伤害、命中和死亡结算，但这次攻击仍会完成攻击流程并消耗回合。它直接移除敌人并生成金币，不发出 `enemy:killed`，因此不计入猎金税、连击战意或层境怒吼等“最终击杀”机制。

### 5.2 每个房间的第一次攻击

圣遗物“先锋一击”使用房间状态 `firstAttackUsed`：

- 每个房间第一次真正发动攻击时生效，不是第一次点击敌人。
- 该次攻击不消耗武器耐久。
- 对尚未行动的敌人额外造成 2 点伤害。
- 攻击路径被拦截、没有发出 `attack:started` 时，不会消耗“第一次攻击”资格。
- 进入新房间后重新计算。

### 5.3 连续主攻击交替使用左右手

圣遗物“潮汐心脏”记录最近一次 `attack:primary-hit` 使用的手：

- 连续两次主攻击使用不同的手时，在第二次主攻击结算后恢复 2 点生命。
- “连续”指连续的主攻击命中事件，中间的移动、翻牌、拾取或无回合操作不会清除记录。
- 进入新房间时清除上一只手的记录。

### 5.4 一次攻击命中至少两名敌人

斧的主目标和斧实际造成伤害的溅射目标会合并判断是否“本次攻击打到至少 2 名敌人”：

- “借势”：50% 概率使本次斧攻击不消耗耐久。
- “开阵”：下一次斧攻击获得 +2 伤害。
- 只计算本次斧攻击的主目标和斧溅射实际造成伤害的目标。
- 不把圣遗物伤害、属性天赋附加伤害或其他后续伤害算入这次斧的多目标判定。

### 5.5 每名敌人的第一次弓攻击

弓天赋使用按敌人 ID 保存的首次攻击记录：

- “先制”：每名敌人第一次受到弓攻击时 +2 伤害。
- “狙击”：距离至少 3 格时，每名敌人第一次受到弓攻击时再 +2 伤害。
- 记录按敌人保存，不按房间重置；敌人 ID 在本局内唯一。
- 后续弓攻击不会再次触发首次攻击加成。

### 5.6 按当前攻击结果准备下一次攻击

以下效果不是全局第 N 次计数，但都属于攻击序列机制：

| 触发来源 | 下一次效果 | 计数或消耗口径 |
| --- | --- | --- |
| 剑成功触发减伤 | “反击”使下一剑 +2 伤害；“攻守一体”再使下一剑 +2 伤害；“回锋”使下一剑不耗耐久。 | 下一把剑攻击匹配后消耗；不按回合过期。 |
| 匕首击杀 | “收割”使下一次匕首攻击 +2；“递刀”使另一只手下一次攻击 +2；“借锋”使另一只手下一次攻击不耗耐久。 | 按武器类别、手和目标匹配后消耗。 |
| 匕首击杀 + 双刃轮舞 | 如果另一只手的下一次攻击也完成击杀，则下一次匕首攻击额外 +2。 | 另一只手的下一次主攻击无论是否击杀都会结束这段等待。 |
| 重武器一击达到目标最大生命 50% | “势不可挡”准备下一次重武器攻击 +3。 | 下一次匹配的重武器攻击消耗。 |
| 灼热克制击杀 | “余烬”准备下一次灼热攻击 +2；“燎原”再增加 1。 | 下一把对应属性武器攻击消耗。 |
| 沉溺克制但未击杀 | “深压”准备下一次攻击该敌人 +3；“深陷”额外给该敌人行动延迟 +1。 | 深压按目标 ID 匹配；深陷每名敌人只触发一次。 |
| 沉溺克制击杀 | “潮生”获得 2 点护甲；“潮生”后“潮生”天赋会准备下一次沉溺攻击 +2。 | 下一次沉溺攻击消耗攻击加成。 |
| 使用增益物品／符咒 | 攻击加成放入待结算列表。 | 下一次符合“任意攻击”或“近战攻击”条件的攻击消耗；不按回合过期。 |

### 5.7 每次攻击都会触发的效果

- “弹道折射”：每次主攻击命中后，对目标身后第一格造成同等伤害；如果该格未翻开，会同时翻开。
- “先锋一击”：只在房间第一次攻击时触发，见上表。
- 武器最后一击：耐久为 1 时仍按完整攻击力结算，随后武器损毁；它不是按全局攻击次数，而是按当前武器耐久决定。
- 武器损毁后会触发“饮血棱镜”“甲胄回响”“断刃继承”“破碎火花”等 `weapon:broken` 效果。

## 6. 按敌人击杀次数或剩余数量计算的机制

| 机制 | 当前触发条件 | 效果 | 重置范围 |
| --- | --- | --- | --- |
| 猎金税 | 每次 `enemy:killed` | 获得 1 金币。 | 无计数上限；随每次最终死亡触发。 |
| 连击战意 | 每次 `enemy:killed` | 当前房间获得 1 层战意，最多 3 层；每层攻击 +2。拾取物品、金币或钥匙会失去 1 层，离开房间清空。 | 按房间保存。 |
| 先锋赏金 | 每个房间第一次由主攻击直接击败敌人 | 获得 2 金币；如果不是最后一击损毁武器，再修复当前武器 1 点耐久。 | 按房间保存。 |
| 清道协议 | 击败敌人后，房间没有其他已翻开的敌人 | 随机翻开 1 张未翻牌。 | 每次满足条件都可触发。 |
| 残局透镜 | 击败敌人后房间只剩 1 名敌人 | 翻开并标记最后一名敌人。 | 每个房间最多触发一次。 |
| 末战誓约 | 房间只剩 1 名敌人时 | 玩家对该敌人的伤害 ×1.3；该敌人对玩家的伤害也 ×1.3。 | 随当前剩余敌人数量动态生效。 |
| 死亡爆裂 | 每次敌人最终死亡 | 对其八邻域敌人造成 2 点伤害，并翻开其中未翻牌。 | 随每次死亡触发。 |
| 层境怒吼 | 跨层累计每击败 10 名敌人 | 翻开当前楼层所有敌人。 | 跨房间、跨楼层累计；触发后归零。 |

“层境怒吼”当前监听的是通用 `enemy:killed` 事件，因此由分裂小怪、陷阱或次级伤害造成的最终击杀也会计入；这点可以作为平衡讨论项。

## 7. 按翻牌、受击或其他次数计算的机制

### 7.1 四次中性卡牌翻开：灰签卜筮

圣遗物“灰签卜筮”有一个跨房间翻牌计数：

- 只有玩家主动翻开的中性灰白卡背计数。
- 翻开 1 张计 1 次，累计到 4 次后，随机窥视当前房间 1 张未翻开的属性卡牌。
- 敌人和属性武器属于属性卡，不计入中性翻牌数。
- 自动翻开、圣遗物导致的翻开和窥视不计数。
- 计数跨房间保留；触发窥视后归零。

### 7.2 受击次数：回响软膏

见“4.5 回合结束恢复”。它按全局回合内的受击次数计数，回合结束统一结算，而不是每次受击立即恢复。

### 7.3 其他一次性事件计数

这些机制有明确的“一次”或“每次”触发，但不是独立的全局攻击计数器：

- 每次翻牌：侧目微光随机窥视相邻八邻域的一张未翻牌。
- 每次翻开敌人：迟滞火种增加行动延迟；警报敌人尝试唤醒一名最近的隐藏敌人。
- 每次敌人进入玩家邻域：伏击敌人现身，满足条件时立即攻击。
- 每次玩家实际恢复生命：疗愈炼成随机使一把已装备武器攻击 +1。
- 每次武器损毁：触发与武器损毁相关的圣遗物。
- 腐蚀陷阱：使左右手已装备武器各损失 1 点耐久；归零的武器按统一损毁流程移除，并发出 `weapon:broken`。
- 每次使用磨刀石修复手中武器：磨石回声使另一只手武器也获得 +1 耐久。
- 每次拾取钥匙：钥匙回响翻开对应门 arrival tile 周围的八邻域卡牌。
- 每次房间清场：安魂铁砧修复当前装备中耐久最低的武器 2 点。

## 8. 每个房间重置或限制一次的机制

以下效果不是按全局回合计数，但会在进入新房间时重置，讨论回合节奏时需要一起考虑：

| 机制 | 房间内限制或状态 |
| --- | --- |
| 先锋一击 | 第一次攻击使用后失效。 |
| 先锋赏金 | 第一次由主攻击直接击杀敌人后领取。 |
| 连击战意 | 击杀获得层数，拾取资源减少 1 层，离开房间清空。 |
| 残局透镜 | 每个房间最多标记一次最后敌人。 |
| 废铁护符 | 每个房间最多一次，主动丢弃背包武器时获得 5 护甲。 |
| 存续本能 | 每个房间最多救命一次；进入新房间时重新可用。 |
| 潮汐心脏的最近手记录 | 进入新房间时清空，但房间内的普通移动和无回合操作不会清空。 |
| 房间奖励 | 首次进入新房间触发奖励选择；选择奖励本身不消耗回合。 |

## 9. 路径、伏击和拦截对回合计数的影响

### 9.1 伏击

- 伏击敌人平时保持隐藏。
- 玩家在一次移动路径中进入其八邻域时，伏击敌人现身。
- 当前伏巢蜘蛛行动延迟为 0，因此现身时可以立即攻击。
- 伏击发生在玩家动作完成、全局回合数增加前；如果因此导致玩家死亡，本次动作不会继续进入正常敌人阶段。

### 9.2 拦截

- 玩家移动、翻牌、攻击、拾取、商人交互和接近门的路径都可能经过敌人攻击范围。
- 只有已翻开、行动延迟为 0、普通攻击冷却为 0 且攻击力大于 0 的敌人可以拦截。
- 攻击目标本身不会拦截前往它的攻击路径。
- 进入敌人射程的步进有 30% 概率被拦截并停止移动。
- 只要登记了拦截者，回合结束时该敌人会先以 50% 攻击力攻击一次，然后跳过本回合常规敌人行动。
- 一次多格移动中的每一步都检查拦截，但整条路径仍只消耗一个回合。

## 10. 回合与攻击相关的状态重置总表

| 状态 | 初始值 | 何时推进 | 何时清零或重置 |
| --- | --- | --- | --- |
| 攻击计数 `attackCount` | 0 | 有效主攻击以 `turnKind: attack` 推进；该攻击此前会发出 `attack:started`。 | 新开局归零；跨房间、跨楼层保留。 |
| 行动计数 `actionCount` | 0 | `turnKind: attack` 或 `turnKind: action` 推进。 | 新开局归零；跨房间、跨楼层保留。 |
| 移动次数 `movementCount` | 0 | `turnKind: movement` 推进；由 `globalTurn - actionCount` 得出。 | 新开局归零；跨房间、跨楼层保留。 |
| 全局回合 `globalTurn`／兼容字段 `turn` | 0 | 每次 `_endTurn()` 按 `turnKind` 推进。 | 新开局或读档使用存档值。 |
| 敌人 `actionDelay` | `initialActionDelay` | 轮到该敌人且延迟大于 0 时 -1。 | 复活时重置；天赋、圣遗物和陷阱可增加。 |
| 敌人 `attackCooldown` | 0 | 轮到敌人且没有行动延迟时推进；攻击后重新写入冷却等待数。 | 复活时清零。被延迟或跳过时不推进。 |
| 复活 `reviveTurns` | 2 | 每次正常回合开始时 -1。 | 复活完成或最终击杀。 |
| 玩家中毒 `poisonedTurns` | 0 | 毒雾陷阱设置为 3；每次全局回合推进后结算并 -1。 | 归零后结束；新开局归零。 |
| 玩家燃烧 `burningTurns` | 0 | 敌人普通攻击命中后设置为 2；每次全局回合推进后结算并 -1。 | 归零后结束；新开局归零。 |
| 敌人自身行动 `ownActionCount` | 0 | 该敌人实际移动或普通攻击后 +1。 | 按敌人实例保存；召唤阈值只对带召唤特性的敌人生效。 |
| 流动兵库攻击数 | 0 | `attack:started` +1。 | 第 3 次触发后归零；跨房间、跨楼层。 |
| 炼金脉搏攻击数 | 0 | 有效发动攻击时 +1。 | 第 10 次触发后归零；跨房间、跨楼层。 |
| 层境怒吼击杀数 | 0 | `enemy:killed` +1。 | 第 10 次触发后归零；跨房间、跨楼层。 |
| 灰签卜筮翻牌数 | 0 | 玩家主动翻开中性卡 +1。 | 第 4 次触发窥视后归零；跨房间。 |
| 弓首次攻击记录 | 空对象 | 每名敌人第一次受到弓攻击时记录。 | 不按房间清除；敌人 ID 在本局内唯一。 |
| 回响软膏受击数 | 0 | 当前全局回合内每次有效受伤 +1。 | `turn:ended` 时按次数恢复并清零。 |
| 房间第一次攻击 | 未使用 | 第一次真正发动攻击后标记。 | 进入新房间时重置。 |
| 房间首杀 | 未领取 | 第一次主攻击直接击杀敌人后标记。 | 进入新房间时重置。 |
| 连击战意 | 0 层 | 最终击杀 +1 层，最多 3 层；拾取资源 -1。 | 离开房间清零。 |

## 11. 当前适合讨论的问题

- [ ] 玩家有利的效果是否都绑定行动计数或攻击计数，避免纯移动刷冷却和奖励？
- [ ] 玩家有害的持续效果是否绑定全局回合，让移动、行动和敌人阶段都能推进它？
- [ ] 使用物品是否都应继续消耗行动？当前生命药水、护甲药剂、增益物品／攻击符文和磨刀石都会消耗一次行动，背包管理和丢弃不会。
- [ ] “第 N 次攻击”是否应该只统计真正命中的攻击，还是保留当前 `attack:started` 的口径？
- [ ] 移动途中被拦截的攻击是否应该保留或消耗“房间第一次攻击”资格？当前实现是不消耗。
- [ ] 炼金脉搏、流动兵库和层境怒吼是否都应该跨房间、跨楼层累计？当前实现是跨房间、跨楼层。
- [ ] 敌人行动延迟中是否应该继续推进普通攻击冷却？当前实现是不推进。
- [ ] 声响陷阱翻出的敌人是否应该跳过当前敌人阶段？当前实现会跳过，并额外给予至少 1 回合延迟。
- [ ] 伏击和拦截是否应当发生在全局回合增加之前？当前实现确实在 `_endTurn()` 之前处理。
- [ ] 分裂小怪、陷阱击杀和次级伤害是否应该计入“每击败 10 名敌人”的层境怒吼？当前实现会计入。
- [ ] 各种“下一次攻击”加成是否都应在等待期间保留？当前实现不按回合过期，只在匹配攻击时消耗。
- [ ] 清道协议的定义目前调用 `run._revealRandomHidden()`；运行时代码中需要补齐或确认这个辅助方法，否则该触发路径可能无法正常执行。
