# 敌人异形骨架方案（模板包 9）

这 30 个后续敌人沿用 `+Y` 朝上、`+Z` 朝前、根关节 `rotationY = -30°` 的纸片空间规则。表中列出每只敌人的承重方式和活动器官；准确的关节坐标、纸片尺寸、连接和五种动作关键帧以 `src/animation/shadow-enemy-variants.js` 为准。所有纸片 `depth = 0`，此阶段不制作贴图。静止姿态接触图见 [enemy-variant-review-v9.png](enemy-variant-review-v9.png)。

| 敌人 ID | 异形轮廓与关节分支 | 攻击器官动作 |
| --- | --- | --- |
| `tide-shadow-cub` | 一后足退化为幼潮尾足，缩小胸腹，头侧长出双片三角潮鳃，尾尖再生分潮尾 | 鳃后收，尾叉与头部错相前扑 |
| `nest-spider` | 低伏八足；腹尾接吐丝器，悬挂左右卵囊 | 吐丝器前探，卵囊滞后摆动 |
| `beetle-guard` | 腹部两扇盾门鞘翅，头部长出撞门角 | 收盾蓄力后开门撞角 |
| `rot-walker` | 偏位头颅、肋间口、背生残臂；一条腿退化成腐生支脚 | 肋口与背臂先后张开 |
| `shellguard` | 取消人腿；棺形躯干以底脊和两条拖地棺根承重，双肩垂下棺门，顶部封棺钉 | 棺根挪行，两门开合护身，封棺钉点刺 |
| `wisp` | 瘦长浮灯，主矛外有副矛影与浮灯骨 | 双矛错相投出 |
| `patrol-hound` | 低头长吻，巡铃下颌和成对香烟须 | 铃颌开合，烟须领先嗅探 |
| `redneedle-salamander` | 瘦长身躯，三枚活动赤针和叉尾 | 赤针逐节竖起，叉尾甩击 |
| `rot-sac-toad` | 无尾宽腹，双侧鸣囊，弹舌端有倒钩 | 鸣囊鼓动后舌钩前射 |
| `claw-beast` | 后足消失，以巨大前爪拖行菱形躯干；腹下水鳍和两片拖潮鳍摆动 | 双爪错相抓取，水鳍滞后 |
| `broodmother` | 取消前足；菱形巨腹由两根育巢支柱和后足承重，裂腹双育门内藏幼首与噬口 | 腹门分开，胎首和噬口相继探出 |
| `moss-colossus` | 面孔埋入胸前，肩上寄树，垂根巨掌，一足石盘化 | 寄树摇晃，巨掌砸落 |
| `sentry-crossbow` | 取消人腿；窄三角躯干立在三脚弩台上，活弩左右弓臂，弩尖监目 | 三脚调整站位，弓臂收紧后监目与弩身前送 |
| `ash-cannon-bug` | 低伏胸腹，前伸炮管，两侧灰囊风箱与测灰触针 | 风箱鼓动，炮口裂瓣展开 |
| `furnace-beetle` | 取消前足；菱形炉腹架在行炉底座与后足上，双炉门鞘翅盖住腹核，背上活炉烟囱 | 底座挪动，炉门掀开，烟囱后仰喷发 |
| `thorn-shell-flower` | 花盘外有双铁壳花萼，花心上生刺冠喉 | 铁壳打开后刺冠突刺 |
| `water-leech-swarm` | 三只斜列尸蛭以群潮联膜相牵，各自有背鳍 | 背鳍错相摆动，前后个体接力咬合 |
| `whirlpool-eye-sac` | 去掉普通侧翼，单眼周围变成四片回潮旋叶 | 旋叶收卷，瞳心牵索和倒钩拉扯 |
| `molten-core-beast` | 暗色宽腹、左右熔核肺囊、熔渣颌和副足 | 肺囊鼓胀，副足撑地后咬击 |
| `redwheel-fire-crow` | 尾羽化轮轴，四片轮焰羽辐各有铰链 | 翼扑与轮焰转动不同相 |
| `cinder-curse-lamp-swarm` | 三个菱形活灯，各有提梁、活门与垂尾 | 三灯活门依次打开施咒 |
| `tide-rite-matriarch` | 双腿退为悬裾，菱形躯干生副祈臂、祭服潮翼和召潮冠 | 副臂与法杖召潮，潮翼滞后展开 |
| `drown-shadow-hunter` | 长颈、偏长右臂、溺影后披与牵潮长钩 | 后披拖曳，长钩探抓 |
| `tidal-spore-sac` | 宽根球上生三枝孢茎，每枝悬孢囊，另有爆孢根 | 三囊错相颤动后爆孢根点射 |
| `revenant-guard` | 一腿退化；方碑躯干由残足与两条墓碑行根支撑，袖中骨刃、头顶魂幡 | 行根牵动墓碑，袖刃与主刃交替刺击 |
| `bomb-wisp` | 去掉常规侧翼，圆形自爆核周围四根倒数灯芯 | 灯芯向内收束，自爆核外冲 |
| `cracked-hunter` | 一臂断失，由裂缝代臂替代；甲片可逐块掀开 | 甲片裂开后右手追猎钩伸出 |
| `broodling` | 减去一对成熟足，幼体腹环延伸，初生裂颚外翻 | 幼颚先张，腹环随后蠕动 |
| `leech-larva` | 三体群缩成单只长蛭，尾部接三环节，口缘有双吸盘 | 吸盘贴近目标，死亡时卷曲侧倒 |
| `tide-shadow` | 去掉浮游者矛杆，改为双裂掌、空面孔与潮底长裾 | 裂掌外伸，空面孔与长裾滞后 |

验收重点：同名主题不共享一整套关节树；攻击器官在蓄力、出击、回收中有明确轨迹；静止、移动、受击和死亡时仍能读出各自轮廓。实际编辑器和游戏画面仍须人工逐只审查。
