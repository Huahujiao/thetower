# 已实装内容

本页列出当前游戏可生成、可获得或可遇到的静态内容。敌人的生命和攻击为固定值；敌人标注的最早出现楼层仅决定其从哪一层起进入生成池，之后的各层仍有机会出现。

## 敌人与首领

敌人的数值为固定值，不随所在楼层成长。例如，第二层出现的猩鬼仍为 4 生命、4 攻击。完整的敌人类型、特性、死亡规则和首批数值见 [敌人.md](./敌人.md)；属性循环、卡背和卡面规则见 [12-attributes.md](./12-attributes.md)；图鉴会直接读取相同的静态数据。

自然生成的敌人在彻底死亡时提供经验，并独立判定圣遗物掉落；经验值、普通战利品与圣遗物掉落概率均为敌人静态数据。召唤物与分裂小怪不提供经验，也不掉落战利品或圣遗物。
