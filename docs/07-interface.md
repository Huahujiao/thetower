# 界面与交互

## 适配范围

游戏页面只面向竖屏手机。页面使用固定的视口布局：棋盘、状态、操作栏、装备栏和背包在一个屏幕内排布，不产生页面滚动或越界。不同屏幕尺寸下，各区块随可用视口缩放并保持可触达。

图鉴页面是独立的阅读界面，可垂直滚动，见 [09-wiki.md](./09-wiki.md)。

## 主界面结构

1. **顶部状态栏**：楼层、生命、护甲、金币、回合数；右侧依次为角色、帮助、设置与日志图标。角色按钮位于设置左侧，问号按钮打开基本玩法说明。
2. **三维棋盘**：正方形卡牌、角色与交互目标。
3. **操作栏**：丢弃、使用、圣遗物主动技能、等待；按钮保持紧凑，并紧贴装备栏上方。
4. **双手装备栏**：左手与右手各一格；双手武器明确显示两只手均被占用。
5. **背包区**：中间为 4×6 背包；左侧纵向排列圣遗物；右侧预留旋转按钮位置。

旋转按钮只有在背包中选中非 1×1 的可旋转物品时显示。

帮助说明以接近全屏的独立弹窗显示，四周均匀留白。弹窗右上角有关闭叉号，也可点击遮罩或按 Escape 关闭；打开时不向棋盘透传点击。

## 三维棋盘

- 默认相机采用倾斜视角，而非完全俯视；默认距离保证完整棋盘可读。
- 支持单指或鼠标拖动平移视角，并支持有限范围内的缩放。
- 缩近时文字仍应清晰；远近平面和最大、最小相机距离应覆盖所有可用缩放范围。
- 可翻牌的卡背使用统一暗色主调，以属性颜色的暗纹区分红、绿、黄、蓝属性，不显示文字；不可翻牌使用不易发灰的深靛蓝主背景，保留两层菱形与四角圆点，并降低图案与边框亮度。卡面右上角显示属性名称，文字颜色与属性一致。
- 敌人、武器、药剂、护甲、增益和磨刀石的卡面均显示名称与关键数值。
- 棋盘外沿是一圈可见的灰色墙，不属于卡牌。棕色门嵌在墙的缺口中，可直接点击交互；门内侧的 arrival tile 仍是普通空卡牌格。
- 第一次点击棋盘目标显示路径虚线和目标环；再次点击同一格才确认行动，点击另一格则切换预览。路径先以直线虚线连接角色和实际到达格；攻击、翻牌、交互等有目标的行动，再从到达格以较高的抛物虚线连接目标格。路径经过已翻开敌人的攻击范围时使用红色虚线，其他路径使用蓝色虚线。
- “侧目微光”窥视的未翻牌显示其半透明正面，用以区别正常翻开和普通卡背。

## 详情面板

详情面板使用统一卡片设计，按长按目标的位置显示：

| 长按对象 | 面板位置 | 显示内容 |
| --- | --- | --- |
| 装备栏中的武器 | 上半屏 | 武器属性与耐久。 |
| 背包物品 | 上半屏 | 物品完整效果与关键属性。 |
| 已获得的圣遗物 | 上半屏 | 效果、激活状态与主动技能冷却。 |
| 棋盘上的敌人、物品、陷阱、金币、钥匙机关、商人 | 下半屏 | 对应对象的完整信息。 |

松开长按即关闭面板。角色、空地、边界门和楼梯不提供棋盘详情面板；角色成长由右上角色按钮单独打开，显示等级、经验、生命上限、左右手力量、掌控、耐久保留率和属性适应。

## 日志与结算

- 战斗与系统日志由右上角日志按钮打开，不在页面底部常驻堆叠。
- 胜败提示使用局部、非全屏的浮层，不遮挡日志按钮。
- 卡牌翻转、悬浮抬升、移动与受击反馈用于传达状态，不改变回合规则。
