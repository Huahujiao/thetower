# 六个敌人拆分素材适配（模板包 10）

输入来自 `island-slicer-web/output` 的六个素材文件夹。原始透明 PNG 保存在 `public/assets/enemies/components-v1/<enemyId>/`；尺寸、来源和 SHA-256 记录在 `src/animation/enemy-component-assets.json`。原图未改写，活动分段通过 `textureFrame.crop` 完成。

| 敌人 | 素材取舍与骨架调整 |
| --- | --- |
| 猩鬼 | 头图自带眼睛和下颌，因此不叠加独立眼图；沿下颌边界拆出活动颌骨。胸部用左右肋骨、胸骨和锁骨甲拼接。手图沿腕部拆分。腿图包含额外中节，加入跗节，分别驱动大腿、中节、胫骨和足爪。省略另一套鬃毛和独立爪尖，删除不再使用的独立指骨。 |
| 烬翅蛾 | 门状翅素材沿金属板与垂膜的连接处划为内、外翅。保留角首、独立复眼、两枚颚钩、胸腹尾甲。六条足沿膝、踝圆盘分段。角已包含在头图中，删除旧触角分支；不叠加另一套腹部。 |
| 腐根芽 | 闭合眼芽是主头，开放花冠缩小后放在后侧，作为花萼。茎图、根球、大小叶、刺枝、行根分别使用；大叶中脉、根爪分段活动。眼已包含在芽图中，不重复叠加。删除旧口部和无贴图的上瓣分支，加入实际叶端骨。 |
| 潮影幼兽 | 素材是悬浮灯笼幽灵，改用灯核—面甲、两侧潮鳍、游裾、悬裾与尾焰结构，重做五种动作。鳍与布条沿连接处拆段，保留运动的滞后关系。长矛、另一盏灯笼和多余冠焰不用。游戏敌人 ID 与战斗数值保持原样。 |
| 伏巢蜘蛛 | 保留沿 Z 轴低伏的头、胸、腹结构。颚钩独立活动，背部素材承担腹壳，次级脸图只取下方丝管作吐丝器。三对腿图沿圆盘关节划为股节、胫节和爪钩；复用一对中足图形成四对腿，各有独立关节和步态相位。省略巨型挂巢和重复眼盘，删除旧卵囊分支。 |
| 甲壳虫卫 | 使用胸甲、腹甲、腹下护甲、头壳和左右盾门翅；头图已有复眼与颚钩，不另加一套脸。长角独立转动。六足沿真实圆盘关节分为股、胫、爪。盾门以素材内侧边缘为枢轴，不再依靠旧末端平移拉动。 |

所有部件仍为 `depth = 0` 的三维空间纸片；根节点朝向为 `rotationY = -30`。贴图链中的关节偏移固定，动作使用旋转带动活动器官，移除旧几何草稿中会拉开接缝的子关节平移。编辑器与游戏使用相同的模板、骨架求值和纹理裁剪。

升级模板包时，只替换这六种敌人的游戏模板。手调过的旧骨架先存为不关联游戏敌人 ID 的“旧版备份”，选中角色的 ID 保持；再次加载不会重复迁移。其余 27 个敌人仍保持原来的几何纸片。

验收资料在 `art/generated/enemy-components-2026-10-01/review/`：

- `editor-<enemyId>.png`：实际 `/animeedit` WebGL 画面，每行一个动作，每列时间比例 0、0.27、0.64、0.85、1。
- `<enemyId>.png`：实际游戏 Canvas 渲染器的同组动作截图。
- `editor-report.json`：150 个页面姿态和 30 次实际动作播放记录。
- `manifest.json`：部件、绑定、尺寸、裁剪、已用与未用素材清单。

`npm run check:animation`、构建以及本次修改文件的 ESLint 检查通过。全项目 ESLint 存在 `island-slicer-web` 原有 42 个错误，未将其作为本次贴图修改的一部分处理。

复现：启动本地 Vite 5173 端口和独立的无界面浏览器调试端口 9228，执行 `node tools/enemy-component-browser.mjs editor-all`，再运行 `python scripts/build-enemy-component-review.py`。测试脚本只用于独立浏览器测试资料，不能指向用户日常浏览器；它会清空测试页面的动画缓存以验证全新模板。
