# 升级、奖励与商店

## 升级天赋

击杀敌人获得经验；升级从最多4个可解锁天赋与“强化体格（最大生命+2，可重复）”中选择。保留前置树，改为换势、守御、调和、求生四条路线，共20节点。

| 路线 | 位置 | 天赋 | 前置 | 效果 |
| --- | --- | --- | --- | --- |
| 换势 | 1A | 踏势 | 无 | 上次实际行动是主动移动时，攻击+1。 |
| 换势 | 1B | 交锋 | 无 | 与上次攻击使用不同武器，且攻击距离至少2格时，伤害+2。 |
| 换势 | 2A | 稳步 | 踏势 | 主动移动后，武器命中时将护甲补足至1。 |
| 换势 | 2B | 接力 | 交锋 | 主攻击击杀后，下次用不同武器攻击体力-1，不叠加。 |
| 换势 | 3 | 行云 | 稳步、接力 | 同时满足移动后攻击和切换武器时，再+2伤害。 |
| 守御 | 1A | 厚壳 | 无 | 首次进入新房间获得2护甲。 |
| 守御 | 1B | 固甲 | 无 | 防具补足护甲的目标值+1；从0护甲直接获得防具护甲时额外+1。 |

## 合成与获得途径

合成按钮随时可打开（探索与商店阶段），面板只列出背包拥有两种原料的方案，每行显示 A+B=C。长按三个物品中的任意一个可查看详情。成品占位不足时按钮禁用；失败不消耗原料或回合。成功消耗对应两个实例，将成品放入背包并推进1回合，无金币费用。第一版无二次合成。

| 基础武器 | 材料 | 合成武器 |
| --- | --- | --- |
| 沉银守剑 | 盾芯 | 城壁剑 |
| 焦痕手斧 | 弹簧 | 回旋斧 |
| 枯骨匕 | 毒囊 | 蚀骨刃 |
| 炭纹长枪 | 锁链 | 锁魂枪 |
| 沉木短弓 | 瞄准镜 | 鹰眼弓 |
| 枯岩重锤 | 配重块 | 断岳槌 |

- 地面随机物品与房间补给：基础武器、防具、消耗品，不生成材料或合成武器。
- 敌人物品掉落：仅六种材料，保持普通敌人的概率掉落和召唤物不掉落。敌人不再掉落武器或圣遗物。
- “地面不生成材料”指不作为房间初始随机物品；敌人死亡掉出的材料仍留在死亡位置，需拾取入包。
- 普通商店可出售全部44种物品，包括材料、合成武器和圣遗物。收藏家继续提供圣遗物选择服务。
- 圣遗物通过开局、房间奖励和商店获得；同名唯一，无“超过五件全部失效”的限制。
