## 新核心机制的暂定规则与风险

- 武器必须用同色和万能球付足费用，不足时不允许攻击、不扣攻击费用，也不触发攻击效果。
- 已移除重复使用递增费用，执一印改为同回合同一实例减1球；其他旧物品组合及旧测试中有关递增或跨回合执一印的断言不在本轮全面适配，以核心检查为准。
- 已修复（2026-10-15）：选中武器且费用足够时，高亮实际支付的同属性或万能灵火；主动移动和自动接近优先消耗未高亮的灵火，保留本次攻击所需的 ID。移动后总球数仍须足够支付完整攻击。
- 最新选择规则（2026-10-15）：球不足时点击武器无效；武器失去完整支付能力时自动取消。武器选中期间禁止手动选球，攻击固定从右到左筛选同属性或万能球；所有无属性操作跳过武器支付组，没有其他球时停止操作。没有武器选中时仅可手动选择一个球，切换选择不累加，该球用于下一次无属性支付。
- 用过的球进入弃球堆；每回合剩余球先供宠物使用再弃掉，抽球堆为空时洗回弃球堆。手中球不参与洗牌，单次供应超过物理球池可用数量时仅抽实际可用球。
- 揭示新敌人补2球，可能存在为获取资源而主动翻怪的收益；风险是否与收益匹配需实测。
- 原“最大体力+1”升级暂替换为“球池永久加入1万能球”，加入弃球堆，不立即入手。整套球池升级奖励尚未重做。
- 旧测试中的数值体力、食物、旧档迁移断言已淘汰；后续不以恢复所有旧测试为任务目标。核心检查入口为 `check:stamina` 和 `check:pets`。
- 已复现检查问题：`scripts/pets-ball-check.mjs:12` 仍调用已移除的物品、圣遗物旧清单页面，得到 `null` 后执行 `includes` 报错；体力球核心检查中的宠物支付流程通过。本轮不修复旧页面断言。
- 全仓 `npm run lint` 会扫描现存切图工具和临时浏览器文件，存在与本任务无关的报错；本轮游戏源代码与测试目录的静态检查已通过，未扩展为全仓清理。
