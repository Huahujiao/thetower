## 4. 新增通用特性

| 特性 | 规则 |
| --- | --- |
| 燃烧 X | 敌人普通攻击命中后，玩家获得 X 个全局回合的燃烧；当前新增敌人每回合造成 1 点伤害，正常受到护甲吸收。状态从攻击后的下一次全局回合开始结算。 |
| 中毒 X | 玩家获得 X 个全局回合的中毒；当前统一为每回合 2 点伤害且无视护甲。状态从施加后的下一次全局回合开始结算。 |
| 疾行 | 追猎时可移动 2 格；若本次确实移动 2 格，则不能再普通攻击。移动 0 或 1 格时仍按普通追猎规则检查攻击。 |
| 牵引 X | 普攻击中后，将玩家向敌人方向拉近 X 格；目标格必须已翻开且为空，否则本次不移动。 |
| 召唤 | 每次敌人实际移动或普通攻击后增加 1 次自身行动计数；达到指定间隔后生成指定生成物，并受场上数量上限限制。 |
| 死亡孳生 | 敌人最终死亡时，在其八邻域内的已翻开空格生成指定数量的生成物；没有足够空间时，剩余生成失败。 |
