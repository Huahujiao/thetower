# 基本玩法

本页说明一局游戏中玩家需要做什么，以及最常用的操作。详细规则、精确数值和对象清单请查看其他设计文档。

## 目标

地牢共五层。穿过房间、积累装备与成长，击败第五层的监视者即可逃出地牢。进入一个新房间时，通常会获得补给或圣遗物奖励；通过门进入下一房间。

## 探索、移动与翻牌

- 已翻开的牌之间可以八方向移动。
- 点击角色相邻八格内的目标会直接执行；更远的目标会先显示预览路径，再次点击同一目标确认。
- 翻未知牌时，角色会先移动到目标周围的可达空格，随后翻开该牌；角色不会直接踏进未知牌。
- 攻击、翻牌和交互的预览中，直虚线表示实际到达的位置，弧形虚线表示最终作用的目标。
- 不可翻开的未知牌会使用深靛蓝牌背，并保留较暗的图案与边框；半透明的牌仅被窥视，尚未翻开。

## 战斗与敌人

- 攻击时，角色会移动到当前武器可命中的位置，再按已装备武器的顺序攻击。武器耐久降到零会损毁。
- 敌人翻开后会受到行动延迟约束；延迟结束后，普通攻击与主动技能分别计算冷却。主动技能可用时优先于普通攻击，两者不会在同一回合同时发起。
- 被动特性可与敌人的攻击或主动技能在同一回合生效。追击敌人可以先移动，再在追上时攻击。

## 背包、装备与成长

- 背包为四行六列，物品会按照形状占格，选中后可旋转。
- 可将武器装备到左右手；消耗品、磨刀石等物品可以在合适时机使用。注意为关键物品留出可放置的空间。
- 击杀自然敌人获得经验。右上角的角色按钮可以查看等级、经验、生命上限、左右手力量、掌控和属性适应。

## 圣遗物与信息

- 灰色边界墙与棕色门始终可见。点击门会走到其内侧的 arrival tile 并进入下一房间；单独点击 arrival tile 只会移动，不会进门。
- 颜色更深、带金色挂锁标记的棕色门需要先拾取对应的钥匙机关；解锁后挂锁会消失，门变为浅棕色。
- 开局选择、房间奖励、收藏家和怪物掉落都可能获得圣遗物；同时最多激活五件。
- 点击左下角的圣遗物图标可查看已获得的圣遗物并切换激活状态。
- 长按棋盘对象可查看详情，右上角日志按钮可回看事件。本帮助可由右上角问号按钮随时打开。

## 快捷判断

- 红色路径表示会经过已翻开敌人的威胁范围；蓝色路径表示当前已知安全。
- 当路线或攻击条件不理想时，可以选择等待，以观察敌人的行动或等待冷却变化。
