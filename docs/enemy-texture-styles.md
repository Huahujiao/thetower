# 敌人贴图风格实验

源文件仍放在 `public/assets/enemies/`。风格副本放在 `public/assets/enemies/styles/<风格 ID>/`，保持原有目录与文件名，尺寸与透明通道逐像素不变。批处理排除整个 `styles` 目录，不会拿已经处理的图片再次加工。

运行全部预设：

```powershell
npm.cmd run enemies:texture-styles
```

当前 `pale`（低饱和度）仅把饱和度降到原来的 62%，保留原图明暗和颜色区别。gamma 为 1、灰白混合为 0，不额外提亮或添加黑白色罩层。以猩鬼头部与衣摆进行对比，红色、黄绿色和骨头暖色仍能清晰区分。参数位于 `scripts/enemy-texture-style-presets.json`。

敌人列表顶部的“风格”下拉框切换整组正面缩略图；各套缩略图分别缓存，来回比较无需重复渲染。详情页视口右上角也可切换风格，部件列表和放大查看同步切换。风格会写入页面 URL，列表与详情之间跳转、切换上一个／下一个敌人时保留。切换只改变显示贴图，不改变模型、相机、动作进度，也不写入编辑器草稿或游戏设置。

后续新增风格时，在预设文件的 `styles` 数组增加一个不同的 `id` 与 `label`，配置颜色参数；做旧、污渍等纹理算法可以继续扩展脚本的 `transform()`。再次运行批处理，生成的注册表会让下拉框自动出现新风格。每套风格使用独立目录及内容版本参数，重新生成后浏览器不会沿用旧副本。

验证所有副本、源文件校验和、尺寸、透明通道与页面选择器：

```powershell
npm.cmd run check:enemy-texture-styles
```
