# 敌人清单

本页只记录敌人对象的静态数值、特性和掉落。行动顺序、行动延迟、冷却和特性的整体规则见 [敌人规则.md](./敌人规则.md)；掉落物的具体数据见 [物品清单.md](./物品清单.md)。

扩充清单没有为新增敌人指定普通物品掉落，因此当前均为无物品掉落；它们的经验和圣遗物掉落率先使用临时平衡值，后续可单独调整。
