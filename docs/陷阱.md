# 陷阱牌

陷阱牌属于牌局场景牌，不属于可拾取战利品。普通牌位有 4% 概率被替换为陷阱，陷阱不参与污染。

## 触发规则

- 陷阱被翻开时立即触发。
- 玩家手动翻开、声响陷阱翻开或未来技能翻开，均使用同一套揭示结算。
- 触发后牌位变为空牌位，不会再次触发。
- 陷阱造成的伤害可以击杀怪物并结算正常掉落，但伤害来源不是“攻击”。

## 当前陷阱

| 陷阱 | 效果 |
|------|------|
| 爆炸陷阱 | 对玩家造成 2 点伤害；对周围 8 格内已经翻开的怪物造成 2 点伤害；不影响未翻开的牌。 |
| 声响陷阱 | 只翻开范围内的怪物牌，不翻开其他牌型；每翻开一个怪物扣 1 点理智；翻出的怪物本回合不攻击。 |

护甲可以吸收爆炸陷阱对玩家造成的普通伤害。声响陷阱翻出的怪物仍按正常翻怪物规则结算其牌面效果；未来具有“翻出时攻击”特性的怪物可覆盖本回合不攻击规则。
