# 陷阱和敌人

本页是当前 `src/game` 运行时的行为摘要；具体敌人数值以 [敌人.md](./敌人.md) 和 `src/game/data/catalog.json` 为准，不包含 `src/legacy` 的历史实现。

## 当前范围

- 4 种陷阱：爆炸陷阱、声响陷阱、腐蚀陷阱、毒雾陷阱。
- 30 种自然生成敌人、3 种生成物和 1 名第五层首领。
- 敌人和武器使用灼热、枯萎、沉溺三种属性；陷阱不具有属性。

## 敌人生成

自然生成池只包含 `minFloor` 不高于当前楼层且没有 `spawnOnly` 标记的敌人。普通房间的目标敌人数约为棋盘面积的 25%，第五层首领房间额外生成监视者。分裂、召唤和死亡孳生生成的敌人不进入自然生成池，也不提供经验、普通掉落或圣遗物掉落。

## 敌人阶段

每次全局回合推进后，当前房间已翻开的敌人按翻开顺序处理：

1. 处理行动延迟、复活计时和再生。
2. 追猎敌人沿已翻开的路径向玩家移动；疾行敌人最多移动 2 格，移动满 2 格时不攻击。
3. 普通攻击冷却就绪且玩家在射程内时攻击。

移动一格、攻击、翻牌、拾取和使用物品都可能推进全局回合；玩家沿长路径移动时，每个经过的格子都会单独结算敌人阶段，所以可能连续受到多次攻击。当前没有额外的敌人拦截或随机截停机制。

## 行为与特性

| 行为／特性 | 当前规则 |
| --- | --- |
| 驻守 | 不主动移动，在射程内且冷却就绪时攻击。 |
| 追猎 | 射程外时移动 1 格；移动后进入射程可在同一阶段攻击。 |
| 伏击 | 隐藏时不动；玩家逐格进入八邻域时现身，并按延迟和冷却处理攻击。 |
| 警报 | 敌人翻开时唤醒距离最近的一名隐藏敌人；唤醒目标不会继续递归触发警报。 |
| 护盾 | 第一次受到伤害时，本次实际伤害最多为最大生命的一半。重武器攻击无视该防御。 |
| 重甲 | 当前是防御标记和数值定位；重武器攻击无视该特性。 |
| 再生 | 敌人行动前未满血时恢复定义中的生命。 |
| 分裂 | 第一次普通攻击后，在最近的已翻开空格尝试生成指定小怪。 |
| 复活 | 第一次生命归零进入假死；两回合后满血复活，期间再次受到伤害会最终击败。 |
| 死亡爆炸 | 最终击败时，若玩家位于指定范围内，造成对应伤害后再移除敌人。 |
| 燃烧 | 普通攻击命中后施加全局回合燃烧，当前每回合 1 点伤害并正常受护甲吸收。 |
| 死亡中毒 | 最终死亡时，在玩家位于八邻域的条件下施加指定回合数的中毒；当前每回合 2 点伤害且无视护甲。 |
| 牵引 | 普通攻击命中后，尝试将玩家向敌人方向拉近指定格数。 |
| 召唤 | 敌人每次实际移动或普通攻击后累计自身行动次数，达到间隔后生成指定小怪并受数量上限限制。 |
| 死亡孳生 | 最终死亡后在八邻域已翻开的空格生成指定数量的小怪。 |

## 陷阱

陷阱翻开时先记录“翻开：……”日志，再立即结算，并记录 `triggeredAtGlobalTurn` 和 `removeAfterGlobalTurn`。已触发陷阱继续留在棋盘上，经过两个后续全局回合后移除，期间不会重复触发。

| ID | 陷阱 | 当前效果 |
| --- | --- | --- |
| `explosion` | 爆炸陷阱 | 对玩家和八邻域内已翻开的敌人造成 2 点伤害。 |
| `alarm` | 声响陷阱 | 翻开半径 2 内的隐藏敌人；这些敌人跳过当前敌人阶段。 |
| `corrosion` | 腐蚀陷阱 | 玩家的体力立即减少 2 点。 |
| `poison-fog` | 毒雾陷阱 | 施加 3 个全局回合中毒，从下一次全局回合开始每回合造成 2 点无视护甲伤害。 |

`拆弹专家`会在陷阱效果结算前安全移除陷阱，并回复 5 点护甲和 5 点生命。陷阱的静态定义见 `src/game/data/traps.js`，图鉴直接读取该定义。
