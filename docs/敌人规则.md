# 敌人规则

本页只说明敌人行动、被动与结算逻辑；每种敌人的数值、行为、技能、掉落见 [敌人.md](./敌人.md)。

## 敌人构成与信息展示

每名敌人由基础生命、攻击、射程、属性、行为、行动延迟、普通攻击冷却、被动特性、死亡规则，以及至多一个主动技能组成。卡面、长按详情和 `/wiki` 都应显示行动延迟、普通攻击冷却、主动技能及其冷却、行为和特性；这些是公开数值，不需要额外机制才可查看。

## 行动顺序

每次玩家消耗回合的行动结束后，当前房间已翻开的敌人按翻开顺序结算。

1. 先处理行动延迟；延迟尚未归零时，本次不移动、不普通攻击、不使用主动技能。
2. 行为为追猎时，可先沿已翻开的路径朝玩家移动 1 格。
3. 主动技能冷却就绪且满足施放条件时，优先使用主动技能。
4. 否则，普通攻击冷却就绪且玩家在射程内时，发动普通攻击。

一次敌人结算中，普通攻击和主动技能不会同时发动；追猎移动与其后攻击并不冲突。被动特性独立结算，可以与移动、普通攻击或主动技能在同一回合发生。

## 行动延迟与冷却

行动延迟是翻开后到首次可行动前的倒计时，对普通攻击和主动技能同时生效。

- 延迟为 0 的伏击敌人在翻开时，若玩家位于其普通攻击范围内，会立刻攻击一次。
- 延迟为 1 的普通敌人翻开当回合不行动，下一回合开始可以行动。
- 更高的延迟用于需要玩家尽快处理的敌人；具体数值由敌人清单定义。

行动延迟不改变主动技能第一次施放的冷却：技能的首次可用仅受行动延迟和施放条件限制。敌人首次发动普通攻击或主动技能后，对应冷却才开始；两套冷却彼此独立，并在之后的敌人结算中自动递减。主动技能未满足施放条件时不会空放，也不会因此开始冷却。

## 行为

- **驻守**：不移动；在射程内且普通攻击冷却就绪时攻击。
- **追猎**：射程外时沿已翻开的最短路径移动 1 格；若移动后进入射程，可在同一回合攻击。
- **伏击**：隐藏时玩家进入其攻击范围会使其现身；延迟为 0 且攻击就绪时立即攻击一次，之后按驻守逻辑行动。

巡逻行为已移除。旧存档中的巡逻敌人会按追猎处理。

## 被动特性与死亡规则

- **护盾**：首次受伤最多损失最大生命的 50%。
- **重甲**：以敌人自身较高生命和较长普通攻击冷却体现，不另设通用运行时效果。
- **再生**：每次该敌人结算前，若未满血则回复其再生数值，默认为 1。
- **分裂**：第一次普通攻击后，在最近的已翻开空格生成不掉落战利品的小怪。
- **复活**：第一次生命归零时进入假死并占格；补刀会彻底击杀，否则两回合后满血复活，并重新进入初次行动延迟。
- **召唤**：主动技能；就绪且有可用已翻开空格时召唤无战利品仆从。
- **自爆**：主动技能；只有玩家处于爆炸范围内时才会施放。被提前击杀时，若玩家仍在爆炸范围内，会造成较小爆炸。

召唤物与分裂小怪不提供经验、普通掉落或圣遗物掉落。
