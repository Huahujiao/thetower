# The Tower 全新物品系统设计

实施版本：2026-09-15；存档版本22。本文已纳入本轮确认，替代初稿中的主动盾牌与旧武器天赋。

## 规模与方向

18把武器（12基础、6合成）、8件被动防具、6件圣遗物、6件消耗品、6件材料，共44种物品。保留背包摆放、场地格子、属性克制、行为序列和基础属性五个变化维度。

## 已确认的共同规则

- 背包固定8列×4行。相邻按物品实际占用格子的上下左右判定，不计斜角；旋转后实时重算。
- 成功移动、旋转背包物品各推进1个全局回合，结算状态与敌人阶段，不恢复体力。选择、取消、失败和形状不变的旋转不推进回合。商店中整理也遵守此规则。
- 所有防具均为被动，不能主动使用。护甲先吸收普通伤害，保留跨房间积累且不设上限；防具以持续减伤、补足护甲或战斗节奏触发为主。
- 消耗品使用、成功合成各推进1回合，不额外恢复体力；体力药实际恢复3。普通移动、翻牌、拾取、交互仍恢复1体力。
- 武器只具有其条目列出的特效，不附带旧类别统一特效。合成不继承未列出的基础武器效果。
- 主攻击伤害：基础攻击与固定加成相加，再乘属性和地形倍率，向下取整，允许为0，然后结算目标防御。
- 三属性循环：灼热→枯萎→沉溺→灼热；克制×1.6，被克制×0.65。物品的其他属性只作为标签或条件。
- 近战射程1使用八邻域距离，射程2以上使用曼哈顿距离，不计算遮挡。最大射程按当前全部加成计算；寻路也检查到达格上的射程。
- 体力加费与减费相加，最终攻击费用最低1。先支付，再结算击杀返还，体力上限10。
- 计数优先使用跨房间延续的“每第N次攻击/受击”；与房间绑定的效果只允许每房间一次。首次进入房间的轻甲不会因中途拾取或重进补发。
- 同名防具、材料和圣遗物效果不叠加。不同来源加成可以叠加；同一来源“下一次”增益只保留一份。
- “其他武器”按具体物品实例区分，包括同型号的另一把武器。
- 行为序列按实际世界行动记录；自动接近敌人也算移动。背包选中不打断序列，整理、合成、使用物品会打断连续移动。
- 纯移动不产生护甲、生命或可累积增益。稳步需要移动后命中；旅者骨牌奖励移动攻击，同时提高连续攻击的体力消耗。传送与敌人拉动不算主动移动。
- 三相轮检查背包是否同时持有三种属性武器，直接改变克制倍率，不维护房间计数。
- 仅主攻击最终击杀触发武器、天赋和圣遗物的击杀收益。爆炸、碰撞、反伤、中毒不触发这些收益，也不参与属性倍率。
- 毒囊相邻武器造成正伤害时附毒；中毒每敌人阶段开始前造成1伤害，持续2次，不叠加，重施刷新为2次。附加当回合会结算第一次。
- 碰撞只伤害被击退者。房间边界视为墙；未翻牌或非敌人物品阻止位移但不造成碰撞伤害。
- 断岳槌的留白检查整个实际形状外缘；自身占格和背包边界不算其他物品。
- 城壁剑攻击前有任意护甲即加伤，结算后最多扣2护甲。这种主动消耗不触发“被敌人打空护甲”。
- 腐藤甲只减免敌人普通攻击，避免中毒或狂战酒被免除；狂战酒自伤绕过护甲且可致命。
- 下一击增益可以跨房间保留，消耗发生在主攻击前；该攻击新产生的增益留给之后的攻击。圣遗物或弹簧产生的待用增益需要仍持有其来源。

## 合成与获得途径

合成按钮随时可打开（探索与商店阶段），面板只列出背包拥有两种原料的方案，每行显示 A+B=C。长按三个物品中的任意一个可查看详情。成品占位不足时按钮禁用；失败不消耗原料或回合。成功消耗对应两个实例，将成品放入背包并推进1回合，无金币费用。第一版无二次合成。

| 基础武器 | 材料 | 合成武器 |
| --- | --- | --- |
| 沉银守剑 | 盾芯 | 城壁剑 |
| 焦痕手斧 | 弹簧 | 回旋斧 |
| 枯骨匕 | 毒囊 | 蚀骨刃 |
| 炭纹长枪 | 锁链 | 锁魂枪 |
| 沉木短弓 | 瞄准镜 | 鹰眼弓 |
| 枯岩重锤 | 配重块 | 断岳槌 |

- 地面随机物品：基础武器、消耗品，不生成防具、材料或合成武器。房间补给仍可提供基础武器、防具、消耗品。
- 敌人物品掉落：六种材料与对应敌人的防具共享原掉落概率并二选一；召唤物不掉落。敌人不掉落武器或圣遗物。
- 防具只通过敌人掉落、普通商店和房间奖励获取，绝不作为房间地面初始物品生成。
- “地面不生成材料”指不作为房间初始随机物品；敌人死亡掉出的材料仍留在死亡位置，需拾取入包。
- 普通商店可出售全部44种物品，包括材料、合成武器和圣遗物。收藏家继续提供圣遗物选择服务。
- 圣遗物通过开局、房间奖励和商店获得；同名唯一，无“超过五件全部失效”的限制。

## 首轮平衡观察

- 圣遗物现在承担构筑契约：三属性、留空、反转克制、移动攻击、低血或单武器。具体倍率与阈值需通过实战验证。
- 检查低费用武器配合弹簧、接力后的体力循环，最低费用1不阻止击杀回体力。
- 普通移动、等待与整理不能产生护甲、生命或可累积战斗增益；只有体力遵循基础回合恢复规则，旅者骨牌的攻击折扣不随移动步数累积。
- 合成武器可从商店直接获得是本轮明确采用的临时规则，后续物品增多再划分来源。
- 重甲敌人仍按旧敌人规则以较高生命体现防御，不新增固定减伤。

## 机制补强（2026-09-15）

- 普通商店第4栏固定为合成材料，购买和刷新后仍保持材料栏；其余栏位继续允许全部物品。
- 新生成的普通房间交替尝试散布、开阔射线、靠墙敌阵，优先保护门、钥匙、商人和通路，无法布置时回退散布。已有存档不重排房间。
- 自动行走中触发升级选择，在当前回合结算完后停止；选择完成后需要重新指定目的地，不自动续走。
- 背包新增构筑状态面板，显示待触发加成、摆放关联、战斗节奏计数与圣遗物生效条件；武器详情同步显示相关效果。
- 保留版本22存档进度，读档更新装备说明、清理旧三相轮和断刃秤的一次性增益，并补齐普通商店材料栏。
- 本轮收窄部分通用固定伤害加成，仍需通过实际游玩验证武器体力效率和流派平衡。

## 本轮试玩说明

- 木盾只在持有时累计普通受击；续命只累计获得天赋后、受击结算时处于低血的生命伤害。换房、整理和重新放入不重置计数。
- 补足护甲取当前护甲与目标值的较大值，不叠加；更高的已有护甲不会被削减。沉溺和灼热攻击补甲均要求实际造成正伤害。
- 三相轮将克制倍率提高至2.2、被克制倍率降低至0.5。与逆克石并用时，先反转关系，再应用倍率和克制天赋。
- 旅者骨牌保留普通移动恢复体力；移动后攻击体力-2，连续攻击体力+1。折扣不随移动步数积累，最终攻击费用仍至少为1。
- 当前已完成构建、静态检查和六组规则回归；建议新开一局体验完整构筑，版本22旧存档也可继续。界面实机体验与流派平衡由试玩进一步验证。
