# 游戏界面与交互

## 适配与布局

根路由面向竖屏手机触屏。顶部显示楼层、等级、金币以及角色、天赋、帮助、设置和日志入口；经验条位于顶部下方。中间是持续渲染的 Three.js 棋盘，底部是护甲、生命／体力、使用按钮和 4 行 × 8 列背包。圣遗物以普通背包物品显示。背包和棋盘的手势、回合费用分别见 [04-inventory.md](./04-inventory.md) 和 [03-turn-and-combat.md](./03-turn-and-combat.md)。

顶部不直接显示全局回合或体力数值。临时中毒、燃烧和下一击增益集中在棋盘左下角状态托盘，可长按查看详情；持续的装备、天赋与圣遗物条件留在相应详情中。背包中实际生效的四向相邻关系，以双方占用格公共边上的短绿色流光带表示；拖拽期间隐藏。条件未满足的圣遗物精灵变暗。

## 棋盘反馈

- 未翻牌使用统一暗灰卡背，不暗示牌内属性。敌人立牌保留红色危险轮廓，用属性色细线和头部圆环区分属性；名称、生命、行动延迟或冷却与机制符号显示在立牌附近。地面物品使用透明精灵；已翻开未拾取的武器在地板上显示对应属性色的柔和光芒。
- 远处目标首次点击预览路径，再次点击相同目标执行；门可点击门本身或门前预览标记确认。入口房的精英门偏红、补给门偏绿，长按门可查看路线说明。逐格移动时落脚格短暂下沉。途中遭敌人攻击会停止长路径。
- 长按背包武器时，仅在玩家原地射程内的已翻开敌人脚下显示淡蓝色、模糊的圆圈加四短线瞄准星；空格不显示。长按已翻开敌人时，在其攻击范围的已翻开空格和玩家所在格显示同形状红色瞄准星。两者慢速缩小、淡出至约半尺寸，再较快放大、淡入，松手即消失。射程 1 用八邻域，射程 2 以上用曼哈顿距离，不检查遮挡。
- 玩家与敌人的临时符号模型有待机、移动、攻击、受击与死亡动作。攻击方与目标的受击动作同时开始；死亡目标先受击再死亡。死亡爆炸或主动自爆使用独立膨胀、闪光、冲击波与消失动作，和普通死亡、普通攻击动作互斥。升级及胜败面板等待相关动画结束才显示。

## 详情、选择和日志

棋盘对象及背包物品长按 150 ms 打开详情，松手关闭。所有详情面板使用黑色半透明背景，能透出部分三维场景；文本保持浅色。武器详情将攻击、射程、体力消耗分成数值行，只显示当前生效的相邻效果；装备可显示前向合成路线，图标不提前透露成品属性。武器标题依次显示属性、类别、星级，防具显示类别和星级。角色、天赋、帮助、设置、日志及商人面板会阻止点击穿透到棋盘。

初始圣遗物、升级天赋及房间奖励使用选择浮层。商人面板处理购买、出售、补货与圣遗物选择。日志按最新事件在前排列，致命伤害原因优先置顶；“复制日志”按钮复制当前显示内容。胜败提示是局部浮层，仍可打开日志。
