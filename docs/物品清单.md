# 物品清单

## 商店专售武器

商店专售武器不由地面或敌人掉落生成；每次货架从这 6 种及其他高级敌人掉落物中抽取 4 件且不重复。

| 类别 | 武器（属性／攻击／射程／耐久／占格） |
| --- | --- |
| 剑 | 黑钢骑士剑（沉溺／6／1／8／3×1） |
| 斧 | 灰烬处刑斧（灼热／8／1／6／4×1） |
| 匕首 | 枯骨刺刃（枯萎／5／1／9／2×1） |
| 长柄 | 深渊长枪（沉溺／7／2／7／4×1） |
| 重武器 | 熔炉战锤（灼热／11／1／5／4×1） |
| 弓 | 枯木复合弓（枯萎／7／3／7／3×1） |

自爆灯灵没有普通物品掉落规则，但仍可按敌人清单的概率掉落圣遗物；首领、召唤物与分裂小怪不掉落普通物品或圣遗物。
