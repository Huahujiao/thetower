# 武器系统

武器全部直接存放在 5×8 背包中。玩家选中背包里的武器后点击敌人即可攻击，不区分左手、右手，也不存在装备栏、卸下操作、耐久、磨刀石、最后一击或武器损毁。

## 攻击费用

攻击会消耗体力并推进一次攻击计数和全局回合。当前按武器类别收费：

| 类别 | 体力消耗 | 基础特效 |
| --- | ---: | --- |
| 匕首 | 2 | 无额外类别特效；击杀、回复体力等效果由匕首天赋提供。 |
| 剑 | 3 | 攻击后，下一次受到的近战伤害降低 40%。 |
| 斧 | 4 | 对目标周围 2 格内最近的其他敌人造成主攻击伤害的 50%。 |
| 长柄 | 4 | 射程 2；从距离 2 命中时将目标击退 1 格，可能触发碰撞伤害。 |
| 弓 | 4 | 基础射程 3；射程提升由弓天赋提供。 |
| 重武器 | 5 | 攻击带护盾或重甲特性的敌人时无视其防御特性。 |

攻击的移动接近路径会逐格结算移动回合；每移动一格回复 1 点体力，直向和斜向相同。攻击本身消耗上述费用。体力不足时不会执行攻击。
