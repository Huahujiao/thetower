# 一局游戏

## 目标

玩家从第一层的起始房间进入地牢，在第五层击败首领「监视者」。首领死亡即获胜；生命降为 0 即失败。

当前可游玩地城采用不分岔的房间序列，用于验证翻牌、路线选择和物品取舍的基础循环。多路径分岔是已确认的后续方向，但不是当前规则；其范围和实施条件见 [10-roadmap.md](./10-roadmap.md)。

初始状态如下：

- 生命为 20/20，护甲为 0，金币为 0。
- 左手装备一把锈剑，右手为空。
- 背包为空。
- 从三个随机圣遗物中选择一个；所选圣遗物立即激活。

## 核心循环

1. 在已翻开的通路中移动，选择值得接近的未知卡牌。
2. 先走到目标卡牌的八邻域，再翻开它；翻牌本身不使角色踏入该格。
3. 拾取装备、药剂、磨刀石和金币，或处理敌人与陷阱。
4. 通过门进入下一个房间，并在首次进入时处理补给奖励或圣遗物奖励。
5. 利用商人或收藏家整理装备、交易物品与管理圣遗物，继续向终点推进。

## 运行状态

| 状态 | 说明 |
| --- | --- |
| 初始圣遗物选择 | 新局开始时必须选择一件初始圣遗物。 |
| 探索 | 可移动、翻牌、战斗、拾取、使用道具和通过门。 |
| 房间奖励 | 首次进入一个新房间时出现；按奖励袋生成补给奖励或圣遗物奖励。 |
| 商店 | 与商人或收藏家相邻后进入；离开后回到探索。 |
| 结算 | 胜利或失败时显示简短结算提示，并可重新开始。 |

## 设计重点

- 未知信息来自卡背与翻牌，而不是不可读的数值迷雾。
- 路线选择应允许撤退：当前已实装敌人驻守原地，不会追击玩家。
- 武器耐久、双手占用、背包形状和补给稀缺共同形成物品取舍。
- 每个房间保持高密度内容，空位仅用于通行与走位。
