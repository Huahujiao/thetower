# 一局游戏

## 目标

玩家从第一层起始房间进入地牢，穿过五层、八个房间，在第五层击败首领“监视者”。首领最终被击败即获胜；玩家生命降为 0 即失败。

当前地城是无分岔的房间序列，用于验证翻牌、路线选择、背包取舍和战斗风险。

## 初始状态

- 生命 20/20，护甲 0，体力 10/10，金币 0。
- 一把“锈蚀短剑”直接放在 5 行 × 9 列背包中。
- 从 3 件随机圣遗物中选择 1 件，圣遗物占背包 1 格并立即生效。

## 核心循环

1. 在已翻开的格子中移动，选择要探索的路线。
2. 接近未知牌并翻开它；翻牌不会让角色踏入该牌所在格。
3. 拾取背包可容纳的武器、药剂、增益物品、金币、钥匙或圣遗物，处理敌人与陷阱。
4. 从背包直接选择武器攻击敌人，或使用物品调整生命、护甲和攻击准备。
5. 通过门进入下一个房间，首次进入新房间时处理奖励。
6. 使用商人交易物品或购买圣遗物，继续向第五层推进。

## 主要状态

| 状态 | 说明 |
| --- | --- |
| 初始圣遗物选择 | 新局开始时必须选择 1 件初始圣遗物。 |
| 探索 | 可移动、翻牌、战斗、拾取、使用物品和通过门。 |
| 房间奖励 | 首次进入新房间时暂停探索，从奖励选项中选择或跳过。 |
| 商人 | 走到商人八邻域后进入商人面板；离开后回到探索。 |
| 结算 | 胜利或失败时显示结算提示，可重新开始。 |

## 资源节奏

玩家每完成一个非攻击回合获得 1 点体力，攻击回合消耗 2–5 点体力；体力上限为 10，翻牌不消耗体力但会回复 1 点。移动路径的每一格都会单独消耗 1 个全局回合并结算敌人阶段，因此长距离移动可能遭到多次攻击。背包中的圣遗物超过 5 件后，所有圣遗物暂时失效；减少到 5 件或以下后恢复生效。

武器没有耐久，不会损毁，也不存在左右手和最后一击。背包形状、六类武器的攻击费用、属性和基础特效构成主要的物品取舍。
