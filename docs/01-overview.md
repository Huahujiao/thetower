# 一局游戏

## 目标

玩家从第一层起始房间进入地牢，经过四章、十二层。每章从精英与补给两条路线中选择一条，之后直接进入首领房；一局实际经过十二个房间。击败第四章首领“监视者”即获胜；玩家生命降为 0 即失败。

当前地城是四章的首版完整流程，用于验证翻牌、分岔、背包构筑和战斗风险。

## 初始状态

- 生命 20/20，护甲 0，体力 10/10，金币 0。
- 一把“锈蚀短剑”直接放在 4 行 × 8 列背包中。
- 从 3 件随机圣遗物中选择 1 件，圣遗物占背包 1 格并立即生效。

## 核心循环

1. 在已翻开的格子中移动，选择要探索的路线。
2. 接近未知牌并翻开它；翻牌不会让角色踏入该牌所在格。
3. 拾取背包可容纳的武器或消耗品，收集金币、钥匙和战利品，处理敌人与陷阱。
4. 从背包直接选择武器攻击敌人，或使用物品调整生命、护甲和攻击准备。
5. 通过门选择精英或补给路线，在分支房和首领房首次进入时处理奖励。
6. 使用商人交易物品或购买圣遗物，击败章节首领后进入下一章。

## 主要状态

| 状态 | 说明 |
| --- | --- |
| 初始圣遗物选择 | 新局开始时必须选择 1 件初始圣遗物。 |
| 探索 | 可移动、翻牌、战斗、拾取、使用物品和通过门。 |
| 房间奖励 | 首次进入分支房或首领房时暂停探索，从奖励选项中选择或跳过。 |
| 商人 | 走到商人八邻域后进入商人面板；离开后回到探索。 |
| 结算 | 胜利或失败时显示结算提示，可重新开始。 |

## 资源节奏

移动、翻牌、拾取和普通交互各回复 1 点体力；背包整理、移入暂存区、丢弃、合成和消耗品使用不自动回复。暂存区自由画布内移动或旋转不推进回合。攻击消耗武器费用，体力上限为 10。移动路径上的一般步进逐格结算；接近目标的最后一步可与拾取或攻击合并为一次回合，途中遭敌人攻击会中断长路径。圣遗物没有数量超载限制。

武器没有耐久，不会损毁，也不存在左右手和最后一击。背包形状、六类武器的攻击费用、属性和基础特效构成主要的物品取舍。
